### 稀有度与「自动收纳」判定（改任何快速收纳逻辑前必读）

**自动收纳**（双击物品、双击装备栏卸下、换装后被替下的旧件归位）在决定"这件东西放哪儿"时，**次元口袋只对金色及以上品质算作有效空间**：

| 品质 | 背包 | 次元口袋 | 判定 |
|---|---|---|---|
| 白 / 绿 / 蓝 / 紫（tier ≤ 3） | 算 | **不算** | 背包放不下 = 没地方放 |
| 金 / 红（tier ≥ 4） | 算 | 算（看口袋剩余格数） | 可先进袋，也可挤掉袋里的低品质物 |

- **单一真源**：`catalog.gd` 的 `POCKET_TIER := 4` 与 `high_quality()`（品质表 `QUALITY_KEYS`：white / green / blue / purple / gold / red = 0–5）。任何新代码判定"高稀有度"都必须调用 `high_quality()`，**不要再写第二个阈值，也不要硬编码 3 或 4**。
- **手动拖拽不受限**：玩家亲手把白色物品拖进次元口袋永远允许（`main.gd` 的 `is_pocket_item()` 恒为 true 就是这一条）；受限的只有"自动收纳"。
- **自动收纳失败时不静默**：不触发那个手势，并在**屏幕中上**弹一次悬浮提示（`main.gd` 的 `notice_popup()`）；绝不把物品悄悄丢到地上。
- **两处刻意的例外**（都是决定过的，别顺手"修"掉）：
  1. **搜刮一键入包**（`session.gd auto_store()`）：背包满时普通物品仍会退进次元口袋——搜刮是玩家站在箱子前作出的决定，不该因为口袋没格而被拒。
  2. **换装被替下的旧件**（`session.gd stow_equipment()`）：紫及以下不进口袋，退路是**掉在脚边、显示成这件装备本身**（单件掉落，既有品质光环也能一按 `F` 拾回），不会装进可搜索的掉落包。
- **卸下有两种口气，这是故意的**：**手势**卸下（双击装备位 / `Ctrl`+左键 / `F`）放不下时**不触发 + 屏幕中上提示**，装备留在身上；而面板上那个**「卸」字按钮**保留原来的说法——它会把装备**从身上卸下来**，放不下就**掉在脚边（显示成装备本身）**。同一个动词、两种兜底，是明确约定，不是 bug。
- **堆叠物品的搬运**：**一次拖动搬整叠**（背包↔仓库、背包↔口袋都一样）。想只搬一部分，用**右键**"拿起"：右键落在堆叠上＝拿起 1 个，**再右键继续加**（上限是该堆叠的数量），鼠标带着光标走，**左键点格子放下这 N 个**；**左键点面板内空白＝取消**（东西放回原处）、**Esc＝取消**、**拖到面板外＝丢地上**。
  - 手上的数量**只是一个视图**：真正扣减发生在左键落地那一刻，所以**取消永远是零副作用的**（不会出现"取消后变两堆"或丢一格）。
  - 右键的旧功能"旋转"**改到鼠标中键**（营地与对局共用同一套控制器；`R` 键一直都能转）。肉鸽面板的右键是它自己的**右键菜单**，没有动。
- **旋转（中键 / `R`）**：转得过来就只转这一件，别的都不动；**转过来放不下时会把挡路的东西挤走**——顺序是**仓库 → 快捷栏 → 背包 → 地上的**，靠 `Catalog.tidy_around()` 先给**被旋转的那一件**落座，所以**被旋转物永远不会是丢的那个**，别的东西也只是换位置（最差落到地上，不会消失）。覆盖营地与对局。
- **堆叠数量徽标**：格子**右下角**的 `×N`，颜色 **#FF9000**（`item_tile.gd STACK_TINT`），营地/对局/交易行三处共用同一渲染器，改一处三处都变。两处都放不下时按上一条的口气处理。**搭上身上的装备拖拽时**：拖到面板**之外**就丢在地上（这是玩家明确的动作），拖到面板内的空白处只是原地不动。
- **面板里 vs 面板外（丢弃区）**：每个面板（含背板与木框）登记自己的范围。**在面板内的空白处松手什么都不会发生**——物品不会被误丢；**拖出面板（含边框以外的整块画面）才是"丢到地上"**。一旦鼠标离开面板，一块**提前渲染好的毛玻璃贴图以 30% 透明度**盖在面板上（`main.gd frost_texture()`，背板图降采样再放大当模糊，只算一次并缓存），所以"面板变糊了"就是"再松手就丢东西"。
- **背包槽也能拖**（营地与对局）：拖到仓库=把背包脱下来存进仓库；拖出面板=背包本体掉在营地地上。**脱下背包时包里的东西不会自动进仓库**，而是走一条单独的算法（见下条）。
- **脱下背包的算法**（`camp_storage.gd unwear_bag()`）：换上**3×3 制式包**（`Catalog.DEFAULT_BAG_KEY`），旧包里的东西按 `keep_order()` 排序**从最珍贵的开始塞**，**塞不下的一律掉在营地地上**，旧包本身也按拖放目标处理（仓库 / 地上）。
  - `keep_order()` = **品质优先，同品质比"价值÷占格"**（1×2 的东西算半价），可堆叠按**整叠**价值算。
  - **性能预算 0.2 ms**：实测 42 件一车货平均 **0.145 ms**（`tests/camp_keep_order.gd` 会因此报错，超了就该退回"品质→单件售价"）。早期版本 0.463 ms 全是 GDScript `sort_custom` 每次比较回调的开销，改成 `PackedInt64Array.sort()` 后才是这个数。
- **搜刮箱是双向的**：搜刮窗开着时，**背包/口袋里的物品和身上穿着的装备都能拖进箱子**（`loot:<搜索引用>`），箱子里放不下就拒绝、东西留在原处；箱子给出去的东西仍然照旧拖进背包或按 `F`。
- **营地地面掉落（背包拖出面板、脱下背包溢出、主动丢东西）**：地上显示成那件东西本身，走过去按 **F** 拾回，**进角色背包（满了才进次元口袋）**；同一时刻最多留 **60 件**，超出时**最旧的一件直接消失**。**离开营地（进对局）时掉落物只留数据、节点全部释放，回营地再按数据重建**；**关闭游戏则直接丢失**（不写存档）。

**搜刮是一个过程**：对着物资箱按 `F` 开始搜索，物品每隔约 1.2 秒浮出一件——普通箱子 4×4、深处教堂 5×5，所以大箱子值得多等一会儿。搜索框与背包同时显示，用鼠标把物品拖进角色背包或次元口袋即可拿走；中途走开搜索会暂停，回来继续。地上散落的物品（阵亡掉包、怪物掉落）直接按 `F` 秒拾，不需要搜索。搜索框右下角的「快捷使用」可以直接用背包里的急救针、血晶和弹药匣，不必先关掉搜索。

边境不再在每个据点堆放物资箱：整张野外只有 6 个稀疏的遗落物资箱，每个地貌区各一个。箱子在开局生成，搜索品质按地貌风险抽取；低档箱也有小概率出金、红物品，高档箱概率更高，具体概率见 [数值平衡](BALANCE.md)。十八处据点都有独立守军；进入或攻击据点后会锁定该场战斗，不再持续补怪。清完全部守军会在据点中央生成一次清剿宝箱，按区域危险度分为绿色、蓝色、紫色、金色四档，必含同档武器、装备和背包，困难区域还会增加遗物。清理状态和奖励在跨天、进出王城及联机中保留，新一局才重置。王城同样需要击败失乡骑士与全部守卫后才出现王庭珍藏。

**使用与装备**：在背包里点选一件物品，右侧面板顶部就是它的按钮——急救针回血、血晶驱散血香、弹药匣补 48 发；背包、武器、银鸦护符和护甲 / 瞄具 / 轻靴则可装备。**搜到的武器与装备可以当场穿到身上提升本局强度**：武器装备后立刻换到手上，持有时按品质提供伤害与攻速加成（白色 +0%、红色 +72% 伤害 / +28% 攻速）；三件装备各自占用护甲 / 瞄具 / 轻靴槽，本局分别提供生命与受击减伤、火力、移速。两枚已装备的银鸦护符各加 12% 武器伤害。装备栏随时可以卸下——双击那个装备位（或 `Ctrl`+左键、或按 `F`）即可：**营地里先回背包、放不下就进仓库**；**对局与肉鸽里只认背包，金色及以上才允许进次元口袋**，放不下就拒绝并弹出提示，装备留在身上，不会丢在脚下。面板上那个**「卸」字按钮**保留原来的说法：它一定把装备卸下来，放不下就掉在脚边（显示成装备本身，按 `F` 拾回）。**装备位上的东西也能直接拖**：拖到背包 / 口袋 / 仓库，或拖到另一个装备位与它互换（只有同类槽位收，护甲换不进瞄具位）。换装时被替下的旧件则会落回你的背包，背包放不下才处理掉。武器槽被卸空时会自动换回角色的临时武器，空槽以灰字显示当前临时武器名。身上的装备只在局内生效，撤离不会带回，阵亡则会连同背包一起散落在地上——穿上它是有风险的变强。武器与装备的品质越高越强，卖掉也更值钱。

**拖拽**：按住物品拖动时，图标会**紧贴鼠标实时跟随**（放大 10%，带品质色底板与名称数量标签），原格子留下虚线轮廓，光标下方按物品真实格数显示落点预览——能放下是金框，放不下会吸附到最近的空位并加一圈发光提示，整个容器都满了才显示红框加斜纹。松手即落位，拖到所有面板之外则丢到地上；**拖动中或选中后按 `R` 旋转**（右键同效），美术贴图会跟着一起转 90°，横放的物品移动后不会被转回竖放。背包内也能这样调整位置；空间不足时旋转会被拒绝并提示，不会把物品挤丢。物品图标铺满格子，名称压在格子底部的半透明条里并自动截断，不会溢出到相邻格子。

撤离成功则背包连同物资一起带回，阵亡或超时则背包、备用背包与身上装备整包散落在地上，只有口袋保全；临时武器不会被夺走，倒地即自动回到手上。开局自带白色 3×3，精英「赤月狐卫」必掉背包，也常掉落它手里的武器。

血晶提高血香并惊动当地栖息区的守军；燃晶消耗价值来降低追击风险、恢复理智。前两天每天第 3 分钟起血潮围绕随机黎明印记收缩，第 5 分钟完成，圈外持续伤害，理智耗尽持续失血。缩圈结束才生成当天 Boss，不再到时直接判死。第一天胜利自动进入第二天；第二天胜利后可以先拾取遗赠，再按 Y 就绪挑战第三天或 N 直接撤离（U 取消就绪）。第三天直接进入最终 Boss 战，获胜后 N 撤离。三个封印各提供全队 55 银币，全部完成额外提供 100；个人背包与口袋的物资仅在撤离成功时计入价值。出战物资立即扣款，离开营地不退款。

## 角色属性与武器战技

### 堆叠上限与「右键分堆」手势（改任何堆叠 / 搬运逻辑前必读）

- **上限只此一表**：`catalog.gd` 的 `STACK_LIMITS`。急救针（`medicine`）与弹药匣（`ammo`）**一叠 3 个**，其余可堆叠物（血晶 / 古城零件 / 银鸦护符 / 鱼饵 / 六类作物与鱼 / 三种种子）**一叠 5 个**；不在这张表里的物品就是"上限 1"，也就是**不可堆叠**，界面上因此不显示数量徽标。`max_stack()` 读这张表，`stacks()` 由它派生，所以"能不能叠"和"能叠几个"不可能各说一套——**别在任何别处再写一遍阈值**。
- **上限只管"怎么堆"，不管"读几个"**：仓库价值、厨房食材进度、出售数量一律按**真实数量**算（`Catalog.units_of_item()`）。把读到的数量夹到上限，会让旧档里一叠 6 个只算 5 个，多出来的那件永远卖不掉。
- **两种搬运手势刻意不同，别合并**：
  - **左键** ＝ 整条目移动（左键拖动、`Ctrl`+左键、双击都照旧把一叠当整体处理）。
  - **右键按住** ＝ 把这个条目拿在手上；**按住期间每按一次左键**，就在鼠标当时那一格放下**一个**：同类没满就堆上去，空格就新起一堆；那一格放不下才退到最近的同类未满堆、再退到最近的空格。**松开右键**把手里剩下的交给鼠标所在的容器；放不进去的**留在原堆**（没落地就没离开源堆，所以"放回原处"不丢件）；**松手在面板外**才是丢到地上。面板内空白 / `Esc` 取消，只收回还没落地的部分。
  - 逐颗落格**不会重排容器**：这是刻意的，否则你刚放好的那一格会被重新打包搬走。
- **降低上限不会毁档**：加载时会把超过上限的旧堆**拆成另一格**（仓库放不下的进溢出暂存），绝不静默截断。

## 2～4 人联机

1. 所有玩家运行相同版本。房主选择“创建 / 加入房间”→“创建 P2P 房间”。
2. 营地复制六位房间号发给朋友；朋友在 P2P 页面输入房间号。
3. 客户端选择装备后点击准备。房主点击出发（每天固定 5 分钟）。
4. 游戏先通过 STUN 探测双方的 UDP 映射并打洞，尝试局域网和公网 ENet 直连；打洞失败时全队在出发前自动切换到专用服务器。手动 IP 直连仍可用于不依赖信令服务器的局域网或端口映射连接。

P2P 房间需要配置可访问的 API 和 UDP 3478 STUN 服务。对称 NAT、严格运营商 NAT 或封锁 UDP 的网络可能无法打洞，届时使用专用服务器；正在进行的远征不能迁移，自动兜底只发生在出发前。没有 Steam 好友接口、房主迁移或局中重连。进入废墟后房间锁定；返回营地可重新加入。客户端断线按阵亡处理，其他人可继续。

新增首次进入注册 / 登录 / 游客选择；账号可使用本地进度或选择云端同步，支持版本冲突检测与本地备份。最多四人的 P2P 房间优先用 STUN 打洞直连，失败时切到服务器权威房间；也保留手动 IP 直连。API 地址在根目录（或导出游戏旁）的 `game.cfg` 修改。

服务器源码、启动命令、端口与部署步骤见 [SERVER.md](SERVER.md)。在线房间需要在 `game.cfg` 配置实际可访问的服务器地址。

## 家园营地

独立湖畔地图，支持种植、离线生长、浇水、钓鱼、金币商店和出征料理。M 打开生成美术的设施导览。玩法、素材与验证说明见 [HOMESTEAD.md](HOMESTEAD.md)。

**种子与鱼饵是真实占格实体**：家园商店买入后先进**守夜人仓库**，仓库满则退**随身背包**（不进次元口袋），都满则余量**掉在营地地上并弹中上提示**（按 F 拾回，物品永不丢失）。播种 / 抛竿扣的是真实实体。**卖价恒低于买价是刻意设计**（晨光麦种 6<12、赤霞萝卜种 9<18、月露草种 13<26、鱼饵 2<3/份），防止"买入立刻倒卖"变成印钞机。

手柄操作与震动设置见 [CONTROLLER.md](CONTROLLER.md)：双摇杆、扳机蓄力、面板光标与拖拽，默认强烈战斗震动。
