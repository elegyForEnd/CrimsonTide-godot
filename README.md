# 血潮守望 · Crimson Tide

Godot 4 / GDScript 原生桌面合作搜打撤游戏。当前交付为可反复游玩的首版，包含完整结算与成长循环；采用哥特二次元插画、独立营地立绘、角色和怪物精灵、手绘地面材质与原生交互界面。视觉改版说明与素材提示词见 `ART-DIRECTION.md`。

## 启动

最新大招调整：Q 先播放 CG，结束后同步释放技能、战场特效与独立爆发音效；三角色 CC0 素材来源、试听和验证说明见 [ULTIMATE-AUDIO.md](ULTIMATE-AUDIO.md)。

- 直接双击根目录 `Start-Game.cmd`，使用目录内已有的 Godot 4.7.2 运行。
- 可携带版本位于 `dist`：双击 `CrimsonTide.exe`，同目录的 `CrimsonTide.pck` 必须保留。
- 编辑源码：使用 Godot 4.7.2 导入 `project.godot`，按 F6/F5 运行主场景。
- 当前便携版使用随项目提供的 Godot 引擎运行已打包 PCK；没有安装独立导出模板，不是裁剪后的发布模板构建。

## 完整循环

标题 → 单人或创建/加入房间 → 营地选择三名角色、三种装备、购买急救针、升级三条天赋 → 标准 8 分钟或长局 15 分钟 → 随机废墟与掉落 → 搜刮、战斗、点亮封印 → 各自撤离或阵亡 → 全员结束后个人与共享奖励结算 → 自动存档 → 营地继续下一局。

三位角色分别提供步枪齐射、远程治疗、近战范围斩。三种装备提供生命、火力和移速取舍。六类战利品占用不同网格，6×4 背包支持选择、旋转、移动与丢弃；银鸦护符提供当局构筑加成。免费和购买的出战急救针不计出售价值，避免反复立即撤离刷钱。

血晶提高血香并招来精英；燃晶消耗价值来降低追击风险、恢复理智。后半局毒雾收缩，圈外持续伤害，理智耗尽持续失血。到达局时限即判未撤离者死亡。三个封印各提供全队 55 银币，全部完成额外提供 100；个人背包仅在撤离成功时计入。出战物资立即扣款，离开营地不退款。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 按住 Shift + WASD | 奔跑（1.45 倍移速）；松开恢复走路 |
| 鼠标左键 | 持续攻击；单手剑三段连击 |
| 1 / 2 / 3 / 4 | 单手剑 / 双手剑 / 法杖 / 步枪；收招后可切换 |
| 空格 / Q / R | 闪避 / 技能 / 装填 |
| 长按 E | 搜刮 / 封印 3 秒 / 救援 3 秒 / 撤离 4 秒 |
| F / B | 急救（倒地时每局一次自救）/ 燃烧一枚血晶 |
| Tab | 背包；选物品、R 旋转、点空格放置；右键丢弃 |
| M / Esc | 战术地图 / 菜单 |

背包和菜单不暂停战斗。撤离受伤会中断；先离场可观战剩余队友。房主离开会关闭整局，尚未统一结算的奖励不保存。

## 2～4 人联机

1. 所有玩家运行相同版本。房主选择“创建 / 加入房间”→“创建房间”。
2. 营地点击“复制邀请地址”，把 IP:24872 发给朋友；朋友输入到加入框。
3. 客户端选择装备后点击准备。房主选择标准/长局并出发。
4. 局域网可直接连接；异地可使用虚拟局域网，或自行设置公网 UDP 24872 端口映射和防火墙。

这是 ENet 房主权威 IP 直连；没有 Steam 好友接口、匹配服务器、NAT 打洞、房主迁移或局中重连。系统不会自动发送邀请给他人。进入废墟后房间锁定；返回营地可重新加入。客户端断线按阵亡处理，其他人可继续。

## 存档与资源

原生 FileAccess JSON 存档：`%APPDATA%/Godot/app_userdata/血潮守望 · Crimson Tide/profile.json`。保存银币、经验、等级对应经验、天赋、角色、装备、音量和战绩；写入临时文件后重命名。没有账号、服务器持久化或反作弊承诺。

- 宋体标题、物品图标、菱形游标、渐隐红色纵向菜单、原生悬停动画：本地资源与 Godot CanvasItem。
- Noto Serif SC：SIL OFL，见 `assets/SERIF-LICENSE.txt`。
- Noto Sans SC：SIL OFL，见 `assets/FONT-LICENSE.txt`。
- Suno 原创纯器乐背景音乐：菜单／营地《营地守望》（2:43），战局《血潮废墟》（2:07）。本地 Ogg 循环、1.8 秒场景交叉淡化，角色语音和奥义期间自动压低音乐；设置可独立调节音乐。生成记录、提示词与文件哈希见 `assets/audio/music/music-manifest.json`，制作说明见 `MUSIC.md`。
- 114 条二次元动作音效与环境音：短促刀光、晶亮法术、灵能枪声、爆发命中、移动和交互；支持方位、距离衰减和分组混音。音效采用 CC0 素材再设计，来源与配方：`assets/audio/library-manifest.json`。
- 30 条免费授权的日语真人录音，映射到 48 个角色语音槽。绯月使用元气少女、雪璃使用文静少女、鸦羽使用冷酷少女演绎，同角色保持统一音色。普攻使用短促发力声，奥义采用通用出招台词；画面恢复最初的原创技能名及中日咏唱文字，与现成真人录音分别管理。设置可独立调节或关闭语音。营地点击人物会播放对应选人台词；重复点击不打断同一句，切换角色会替换当前语音，离开营地立即停止。

## 工程与验证

- `scripts/session.gd`：权威模拟、ENet RPC、战斗、物资、独立撤离、结算。
- `scripts/ruins.gd`：种子地图、碰撞与视线。
- `scripts/battlefield.gd`：原生 Node2D 地图与角色绘制、地图、特效。
- `scripts/main.gd`：原生 Control UI、输入、音效与存档接入。
- `scripts/catalog.gd` / `profile.gd`：角色物品资源数据、网格规则、成长存档。
- `tests/systems.gd`：261 项规则与 30 种子可达性验证。
- `tests/ui.gd`：图形运行、真实输入事件、完整 UI 循环与截图。
- `tests/network.gd`：独立进程 2 人和 4 人联机、RPC 技能、先后撤离与奖励验证。

运行规则测试：`Godot_v4.7.2-stable_win64_console.exe --headless --path . --script tests/systems.gd`。

本机多进程联机已测试；未进行跨公网、丢包和长时压力实测。三名角色新增每种武器四姿势分帧动画，配合前摇、命中帧、收招、残影与位移；不是完整八方向骨骼动画。详见 `COMBAT-UPDATE.md`。
