# 血潮守望 · Crimson Tide

Godot 4 / GDScript 原生桌面合作搜打撤游戏。当前交付为可反复游玩的首版，包含完整结算与成长循环；采用哥特二次元插画、独立营地立绘、角色和怪物精灵、手绘地面材质与原生交互界面。视觉改版说明与素材提示词见 `ART-DIRECTION.md`。

三日远征玩法已接入：第一天禁撤离、前两天随机黎明 Boss、第二天可撤离、第三天挑战血潮女王。详细技能与规则见 [三日远征设计](EXPEDITION.md)。新版独立运行文件：`dist/CrimsonTide-ThreeDays.exe`。

最新地图：月冠边境，6400×4800，六大地貌区、18 个据点、三桥四撤离点；M 查看地形、资源和路线标记。详见 [MAP-UPDATE.md](MAP-UPDATE.md)。

## 完整循环

标题 → 单人或创建/加入房间 → 营地选择三名角色、三种装备、购买急救针、升级三条天赋 → 每个探索日 5 分钟（第 3 分钟缩圈） → 第一天搜刮并击败黎明 Boss → 第二天圈重置、可各自撤离 → 第二次黎明击败强化 Boss → 选择撤离或进入第三天挑战血潮女王 → 全员结束后个人与共享奖励结算 → 自动存档 → 营地继续下一局。

三位角色分别提供黑铁短剑、祭祀短杖与破碎大剑三把**临时武器**，它们只是开局保命用的，永远不能升级、不能掉落，也一定弱于同类的局内武器。三种装备提供生命、火力和移速取舍。六类战利品占用不同网格。银鸦护符提供当局构筑加成。免费和购买的出战急救针不计出售价值，避免反复立即撤离刷钱。

**武器只能捡到并装备后才能使用**：局内不再有 1～4 换武器的快捷键，营地也不能预设武器。四把真正的武器（守夜步枪、绯红单手剑、破晓双手剑、星辉法杖）全部作为战利品存在，捡进背包后装备到武器槽才会握在手里；卸下或阵亡时会自动换回角色的临时武器，所以任何时刻都有武器可用。临时武器的定位如下：

| 角色 | 临时武器 | 特点 |
|---|---|---|
| 绯月 | 黑铁短剑 | 攻击距离短（84）、攻速快（0.30 秒）、伤害低（13） |
| 雪璃 | 祭祀短杖 | 远程法术弹道（520），伤害低（15），出手前有短暂吟唱 |
| 鸦羽 | 破碎大剑 | 攻速最慢（0.98 秒）、伤害略高（30）、范围大（150） |

储物分为两层。**次元口袋**是固定 4×4 的永久容器，内容写入 `profile.json`：阵亡、超时、退出游戏都不会失去它。**角色背包**是局内通过搜刮获得的独立空间，品质决定大小并可以死亡掉落：白色 3×3、绿色 4×4、蓝色 5×5、紫色 6×6、金色 7×7、红色 8×8。

六类战利品占用不同网格：血晶 1×1、古城零件 2×1、月蚀遗物 2×2、急救针 1×2、银鸦护符 1×2、弹药匣 2×1，背包 1×1。**武器占 2×2，装备占 1×2**：武器与装备共用背包品质的六档颜色，箱子、精英怪和地面掉落都可能出现，品质越高加成越大、卖价也越高。

**搜刮是一个过程**：对着物资箱按 `F` 开始搜索，物品每隔约 1.2 秒浮出一件——普通箱子 4×4、深处教堂 5×5，所以大箱子值得多等一会儿。搜索框与背包同时显示，用鼠标把物品拖进角色背包或次元口袋即可拿走；中途走开搜索会暂停，回来继续。地上散落的物品（阵亡掉包、怪物掉落）直接按 `F` 秒拾，不需要搜索。搜索框右下角的「快捷使用」可以直接用背包里的急救针、血晶和弹药匣，不必先关掉搜索。

边境不再在每个据点堆放物资箱：整张野外只有 6 个稀疏的遗落物资箱，每个地貌区各一个。十八处据点都有独立守军；进入或攻击据点后会锁定该场战斗，不再持续补怪。清完全部守军会在据点中央生成一次清剿宝箱，按区域危险度分为绿色、蓝色、紫色、金色四档，必含同档武器、装备和背包，困难区域还会增加遗物。清理状态和奖励在跨天、进出王城及联机中保留，新一局才重置。王城同样需要击败失乡骑士与全部守卫后才出现王庭珍藏。

**使用与装备**：在背包里点选一件物品，右侧面板顶部就是它的按钮——急救针回血、血晶驱散血香、弹药匣补 48 发；背包、武器和护甲 / 瞄具 / 轻靴则是「装备」。**搜到的武器与装备可以当场穿到身上提升本局强度**：武器装备后立刻换到手上，持有时按品质提供伤害与攻速加成（白色 +0%、红色 +72% 伤害 / +28% 攻速）；三件装备各自占用护甲 / 瞄具 / 轻靴槽，本局分别加成生命、火力与移速。装备栏随时可以「卸下」，换下来的旧装备会回到背包，放不下就掉在脚边；武器槽被卸空时会自动换回角色的临时武器，空槽以灰字显示当前临时武器名。身上的装备只在局内生效，撤离不会带回，阵亡则会连同背包一起散落在地上——穿上它是有风险的变强。武器与装备的品质越高越强，卖掉也更值钱。

**拖拽**：按住物品拖动时，图标会**紧贴鼠标实时跟随**（放大 10%，带品质色底板与名称数量标签），原格子留下虚线轮廓，光标下方按物品真实格数显示落点预览——能放下是金框，放不下会吸附到最近的空位并加一圈发光提示，整个容器都满了才显示红框加斜纹。松手即落位，拖到所有面板之外则丢到地上；**拖动中或选中后按 `R` 旋转**（右键同效），美术贴图会跟着一起转 90°，横放的物品移动后不会被转回竖放。背包内也能这样调整位置；空间不足时旋转会被拒绝并提示，不会把物品挤丢。物品图标铺满格子，名称压在格子底部的半透明条里并自动截断，不会溢出到相邻格子。

撤离成功则背包连同物资一起带回，阵亡或超时则背包、备用背包与身上装备整包散落在地上，只有口袋保全；临时武器不会被夺走，倒地即自动回到手上。开局自带白色 3×3，精英「赤月狐卫」必掉背包，也常掉落它手里的武器。

血晶提高血香并惊动当地栖息区的守军；燃晶消耗价值来降低追击风险、恢复理智。前两天每天第 3 分钟起血潮围绕随机黎明印记收缩，第 5 分钟完成，圈外持续伤害，理智耗尽持续失血。缩圈结束才生成当天 Boss，不再到时直接判死。第一天胜利自动进入第二天；第二天胜利后可以先拾取遗赠，再按 Y 就绪挑战第三天或 N 直接撤离（U 取消就绪）。第三天直接进入最终 Boss 战，获胜后 N 撤离。三个封印各提供全队 55 银币，全部完成额外提供 100；个人背包与口袋的物资仅在撤离成功时计入价值。出战物资立即扣款，离开营地不退款。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 按住 Shift + WASD | 奔跑（1.45 倍移速）；松开恢复走路 |
| 鼠标左键 | 持续攻击；单手剑 / 黑铁短剑三段连击 |
| — | 没有换武器按键：捡到武器并在背包里装备后才能换用，空槽时自动使用角色的临时武器 |
| 空格 / Q / R | 闪避 / 技能 / 装填 |
| 长按 E | 封印 3 秒 / 救援 3 秒 / 撤离 4 秒 |
| F | 开始搜索容器 / 秒拾地上掉落物；没有可捡可搜时使用急救针（倒地时自救也用它） |
| B | 燃烧一枚血晶 |
| Tab | 背包界面：角色背包 + 次元口袋双网格、鼠标拖拽搬运、**拖到装备栏 / 背包槽或双击即可装备**（武器 / 护甲 / 瞄具 / 轻靴 / 背包四个槽加背包柜换装）、点选物品后使用或装备；物资箱卡片按真实占格显示；**R 旋转**（右键同效，拖拽中也可）；关闭搜索框 |
| M / Esc | 战术地图 / 菜单 |
| Y / N / U | 第二天胜利后：留下挑战 / 直接撤离 / 取消就绪；最终胜利后 N 撤离 |

背包和菜单不暂停战斗。撤离受伤会中断；先离场可观战剩余队友。房主离开会关闭整局，尚未统一结算的奖励不保存。

## 2～4 人联机

1. 所有玩家运行相同版本。房主选择“创建 / 加入房间”→“创建房间”。
2. 营地点击“复制邀请地址”，把 IP:24872 发给朋友；朋友输入到加入框。
3. 客户端选择装备后点击准备。房主点击出发（每天固定 5 分钟）。
4. 局域网可直接连接；异地可使用虚拟局域网，或自行设置公网 UDP 24872 端口映射和防火墙。

这是 ENet 房主权威 IP 直连；没有 Steam 好友接口、匹配服务器、NAT 打洞、房主迁移或局中重连。系统不会自动发送邀请给他人。进入废墟后房间锁定；返回营地可重新加入。客户端断线按阵亡处理，其他人可继续。
