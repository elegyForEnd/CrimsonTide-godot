# 血潮守望 · Crimson Tide

Godot 4 / GDScript 原生桌面合作搜打撤游戏。当前交付为可反复游玩的首版，包含完整结算与成长循环；采用哥特二次元插画、独立营地立绘、角色和怪物精灵、手绘地面材质与原生交互界面。视觉改版说明与素材提示词见 `ART-DIRECTION.md`。

## 启动

**双击 `dist/CrimsonTide.exe` 即可，无需安装、无需 Godot、无需联网。**

- 单文件发布：PCK 已内嵌，没有旁边的 `.pck`；整个 `dist` 可以随意改名或剪切到任意位置。
- 体积 162 MB，Windows x86_64（Godot 4.7.2 release 模板，x86_64 架构）。
- 存档写入 `%APPDATA%/Godot/app_userdata/血潮守望 · Crimson Tide/profile.json`；删除 exe 不会丢进度。
- 脚本以二进制 `.gdc` 打包，exe 内不含明文源码。
- 有用户配置文件（公司 / 产品名 / 版本 1.0.0.0）与应用图标。

### 重新打包

本机已安装 4.7.2 导出模板（无法从 GitHub 获取时，用 HTTP Range 从
`https://downloads.godotengine.org` 取 `templates/windows_release_x86_64.exe` 与 `templates/version.txt`
即可，无需下载整个 1.2 GB 模板包）。之后：

```
Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release "Windows Desktop" "dist/CrimsonTide.exe"
```

### 从源码运行

- 使用 Godot 4.7.2 导入 `project.godot`，按 F6/F5 运行主场景。
- 需要看完整日志：`Godot_v4.7.2-stable_win64_console.exe --path . --verbose`。

`tools/make_icon.gd` 可把 `assets/icon.svg` 重新栅格化为多尺寸 `.ico`（换图标时用）。

## 完整循环

标题 → 单人或创建/加入房间 → 营地选择三名角色、三种装备、购买急救针、升级三条天赋 → 标准 8 分钟或长局 15 分钟 → 随机废墟与掉落 → 搜刮、战斗、点亮封印 → 各自撤离或阵亡 → 全员结束后个人与共享奖励结算 → 自动存档 → 营地继续下一局。

三位角色分别提供步枪齐射、远程治疗、近战范围斩。三种装备提供生命、火力和移速取舍。六类战利品占用不同网格。银鸦护符提供当局构筑加成。免费和购买的出战急救针不计出售价值，避免反复立即撤离刷钱。

储物分为两层。**次元口袋**是固定 4×4 的永久容器，内容写入 `profile.json`：阵亡、超时、退出游戏都不会失去它。**角色背包**是局内通过搜刮获得的独立空间，品质决定大小并可以死亡掉落：白色 3×3、绿色 4×4、蓝色 5×5、紫色 6×6、金色 7×7、红色 8×8。

**搜刮是一个过程**：对着物资箱按 `F` 开始搜索，物品每隔约 1.2 秒浮出一件——普通箱子 4×4、深处教堂 5×5，所以大箱子值得多等一会儿。搜索框与背包同时显示，用鼠标把物品拖进角色背包或次元口袋即可拿走；中途走开搜索会暂停，回来继续。地上散落的物品（阵亡掉包、怪物掉落）直接按 `F` 秒拾，不需要搜索。

**拖拽**：按住物品拖动时，图标会**紧贴鼠标实时跟随**（放大 10%，带品质色底板与名称数量标签），原格子留下虚线轮廓，光标下方按物品真实格数显示落点预览——能放下是金框，放不下会吸附到最近的空位并加一圈发光提示，整个容器都满了才显示红框加斜纹。松手即落位，拖到所有面板之外则丢到地上；拖动中右键旋转。背包内也能这样调整位置。

撤离成功则背包连同物资一起带回，阵亡或超时则背包与备用背包整包散落在地上，只有口袋保全。开局自带白色 3×3，精英「血香猎手」必掉背包。

血晶提高血香并招来精英；燃晶消耗价值来降低追击风险、恢复理智。后半局毒雾收缩，圈外持续伤害，理智耗尽持续失血。到达局时限即判未撤离者死亡。三个封印各提供全队 55 银币，全部完成额外提供 100；个人背包与口袋的物资仅在撤离成功时计入价值。出战物资立即扣款，离开营地不退款。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 按住 Shift + WASD | 奔跑（1.45 倍移速）；松开恢复走路 |
| 鼠标左键 | 持续攻击；单手剑三段连击 |
| 1 / 2 / 3 / 4 | 单手剑 / 双手剑 / 法杖 / 步枪；收招后可切换 |
| 空格 / Q / R | 闪避 / 技能 / 装填 |
| 长按 E | 封印 3 秒 / 救援 3 秒 / 撤离 4 秒 |
| F | 开始搜索容器 / 秒拾地上掉落物（倒地时自救也用它） |
| B | 燃烧一枚血晶 |
| Tab | 背包界面：角色背包 + 次元口袋双网格、鼠标拖拽搬运、背包柜换装；R 旋转；关闭搜索框 |
| M / Esc | 战术地图 / 菜单 |

背包和菜单不暂停战斗。撤离受伤会中断；先离场可观战剩余队友。房主离开会关闭整局，尚未统一结算的奖励不保存。

## 2～4 人联机

1. 所有玩家运行相同版本。房主选择“创建 / 加入房间”→“创建房间”。
2. 营地点击“复制邀请地址”，把 IP:24872 发给朋友；朋友输入到加入框。
3. 客户端选择装备后点击准备。房主选择标准/长局并出发。
4. 局域网可直接连接；异地可使用虚拟局域网，或自行设置公网 UDP 24872 端口映射和防火墙。

这是 ENet 房主权威 IP 直连；没有 Steam 好友接口、匹配服务器、NAT 打洞、房主迁移或局中重连。系统不会自动发送邀请给他人。进入废墟后房间锁定；返回营地可重新加入。客户端断线按阵亡处理，其他人可继续。

## 存档与资源

原生 FileAccess JSON 存档：`%APPDATA%/Godot/app_userdata/血潮守望 · Crimson Tide/profile.json`。保存银币、经验、等级对应经验、天赋、角色、装备、音量和战绩，以及次元口袋与背包柜的全部内容和格子位置；写入临时文件后重命名。没有账号、服务器持久化或反作弊承诺。

- 主视觉、三角色精灵、三张独立营地立绘、四类怪物和地面材质：本项目使用内置 imagegen 生成。
- 宋体标题、物品图标、菱形游标、渐隐红色纵向菜单、原生悬停动画：本地资源与 Godot CanvasItem。
- Noto Serif SC：SIL OFL，见 `assets/SERIF-LICENSE.txt`，随 `dist` 一并分发。
- Noto Sans SC：SIL OFL，见 `assets/FONT-LICENSE.txt`，随 `dist` 一并分发。
- 程序合成环境音、枪声、技能、受击、搜刮音效：`scripts/sound.gd`。
- Godot 引擎为 MIT 许可；引擎许可文本内嵌于导出模板，可从 godotengine.org 获取。

## 工程与验证

- `scripts/session.gd`：权威模拟、ENet RPC、战斗、物资、独立撤离、结算。
- `scripts/ruins.gd`：种子地图、碰撞与视线。
- `scripts/battlefield.gd`：原生 Node2D 地图与角色绘制、地图、特效。
- `scripts/main.gd`：原生 Control UI、输入、音效与存档接入。
- `scripts/catalog.gd` / `profile.gd`：角色物品资源数据、六档背包品质与网格规则、容器排版与堆叠、次元口袋存档。
- `tests/systems.gd`：361 项规则与 30 种子可达性验证。
- `tests/ui.gd`：图形运行、真实输入事件、完整 UI 循环与截图。
- `tests/network.gd`：独立进程 2 人和 4 人联机、RPC 技能、先后撤离与奖励验证。

本机多进程联机已测试；未进行跨公网、丢包和长时压力实测。三名角色新增每种武器四姿势分帧动画，配合前摇、命中帧、收招、残影与位移；不是完整八方向骨骼动画。详见 `COMBAT-UPDATE.md`。
