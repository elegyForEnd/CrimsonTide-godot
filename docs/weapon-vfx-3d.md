# 武器三维 VFX 实现

> 当前生产制作方法见 [武器 VFX：参考设计与引擎实现](weapon-vfx-authored.md)。下文为历史迭代记录；当前释放、弹体和尾迹由手工曲面与程序材质构成，不再投射完整技能图，也不读取 V6 参考裁片。

2026-10-19。全部 48 把肉鸽武器与 21 个剧情/临时武器入口使用同一套空间特效系统。人物保留二维动画；刀光、施法、光束、命中、烟雾和飞行拖尾由三维网格与粒子组成。贴图承担材质细节和弹体零件，不再由一张完整技能图片承担整个释放动作。

## 实际接入

- `scripts/weapon_combat_vfx_3d.gd` 接收真实 windup、strike、impact、spell_beam、spell_arc、spell_burst；零伤害不生成命中，重复命中去重，不改玩法字典。
- `scripts/weapon_release_vfx_3d.gd` 按事件时钟逐段生成 ArrayMesh 刀光、不同平面的重击、窄刺、开放旋斩和施法薄膜。历史段独立消失；粒子分别出生、漂移、受重力、死亡。烟雾使用原始灰度密度图加空间材质流动。
- `scripts/weapon_projectile_vfx_3d.gd` 按真实 fx_id 记录三维弹道历史，按距离插值，生成动态 UV ribbon；独立原画弹体平面、实体亮芯和 MultiMesh 粒子。传送断开轨迹、死亡尾迹连续衰减。
- `scripts/weapon_effect_profiles.gd` 明确列出 48 把武器及剧情映射。每把武器的释放、弹体、烟雾、命中共享身份、色板与物性；14 类物质控制宽度、流速、剪切、粒子和消散节奏。三段连击方向、战技动作、蓄力状态和实际 reach/width 分别读取事件。

剧情与搜打撤已有真实 Node3D 世界，特效直接挂入其世界，参与 Camera3D 投影、地形高度和原生遮挡。肉鸽当前另有独立的 Canvas 平面场景，`weapon_vfx_viewport.gd` 将同一套真实三维特效渲染到透明 SubViewport，校准其滚屏、人物高度与 UI 缩放后合成；该模式的二维地图没有新增三维遮挡几何。不能把这层合成说成整个肉鸽地图已改为三维。

英雄大招、敌人/Boss 特效、UI 掉落提示继续由现有系统负责。旧 Canvas 武器模块保留为兼容与独立审查入口，生产武器事件走空间系统，不重复叠画。

## 素材与统一

先前制作的 22 张原创 ImageGen 图片与 prompt、尺寸、SHA-256 保存在 `assets/combat/imagegen-mechanics/layered-v2/` 及 manifest。运行时按用途取密度图与弹体零件；完整释放原画保留兼容来源，不作为三维刀光的整张替代物。本机英雄联盟解码资源仅在忽略的 build 研究目录，未作为运行资产。

## 预算

释放/命中上限 96 组；弹体上限 96 条；每条历史最多 24 点，重采样最多 48 点；弹体粒子批次最多 384 个。超过 16/40 组释放自动降低次要网格细分、碎片和烟层；最高负载时网格按 30 Hz 重建，事件时间保持连续，正常战斗逐帧更新。切图、重置与到期立即摘除实例。

## 普攻、蓄力重击、战技分别表现

三类动作由明确的 normal/heavy/art 描述区分，沿用武器自身色板与物性。普攻为单层短切、快速回收；重击按武器采用下劈、坠击或集中贯穿；战技按身份采用错向多切、地面喷发、扇出与内吸等独立运动。网格拓扑、运动、时序及碎散不同，不以同一效果整体放大代替。真实攻击形状、弹数和伤害范围仍来自原玩法。

左键蓄力接通 hold_charge → hold_ready → hold_cancel/charged strike。聚能粒子沿实际武器采样点进入刃面，满蓄力短闪后保持呼吸亮芯；持续持有不提前消失，松手由重击取代，取消立即清理。弹体与延迟爆发通过 build_context / vfx_action 携带原动作，换装或后续普攻不改变已发射特效。

新增 `tests/weapon_action_vfx.gd` 覆盖全部 69 个武器入口的三类拓扑、色板与完整蓄力周期；实际 GPU 测试 `tests/weapon_action_vfx_visual.gd` 对 48 把武器分别检查三类释放、聚能、满蓄力持续与取消，336 项通过。三列对照生成命令为上述预览脚本加 `-- --actions`，输出 `build/vfx-3d/action-comparison.png`，动态帧依次演示普攻、聚能、满蓄力、重击与战技。


## 单把武器的主体重设计

48 把武器的释放主体使用逐把编写的中心轨迹，见 `weapon_release_vfx_3d.gd::authored_path`。刺剑沿轴穿刺、回环弯刀回卷、双刃错向双切、细剑薄月弧、断誓断续切面、镜花错位双刃；大剑连续刃尖弧线取消截平的底部。重锤锤头落下后才出现地面折线裂缝、掀起碎石和扩散尘浪。普攻小接触、重击前向集中断层、战技多向地面喷发分别设计。范围、弹数、实际伤害形状仍由玩法事件决定。

远程弹体同时叠加原生三角网格轮廓：飞针、分瓣穿甲芯、羽刃、折电、月牙、错位双片、旋转魂丝、向内旋涡、星芒和折页；贴图继续提供内部绘制细节。网格跟随真实弹体中心，不更改弹道。每条最多六组主体瓣片，高并发降至两组。

`SIGNATURES` 为 48 把武器与四把独立剧情武器的显式设计参数；`attack.style` 选择主体动作，signature 决定切面与碎散。测试对 48 把主体轨迹在移除色彩、贴图与外围装饰后取样比较，避免仅靠换色建立差异。2026-10-19 本轮动作检查 2196 项、世界空间检查 2355 项、三动作 GPU 检查 336 项通过。

完整预览：`Godot_v4.7.2-stable_win64_console.exe --path . --script tools/preview_weapon_world_vfx.gd -- --all`，随后 `python tools/build_weapon_preview_gallery.py`，生成 `build/vfx-3d/all/index.html` 与 69 个入口的独立视频。`-- --designs` 可单独生成大剑、重锤对照与动态片段。

本轮弹体原生轮廓加入后，弹体逻辑 297 项、含主体隔离与深度遮挡的 GPU 检查 24 项、生产战斗接入 9441 项均通过。全量 69 段动态视频与 9 段分组总览已重新生成。


主体与烟雾比例调整：释放主体宽度 ×1.35，主切面不透明度权重 1.30→1.48，身份轮廓尺寸 ×1.18；烟雾卡片尺寸 ×0.78、不透明度 ×0.82。远程弹体绘制主体和原生轮廓 ×1.25，密度尾迹宽度 ×0.80、透明度权重 .82→.68。以上只调视觉尺寸与层级，中心轨迹、时序、伤害和射程不变。动作逻辑 2196 项、弹体逻辑 297 项、动作 GPU 336 项、弹体 GPU 24 项通过。


横排贴片修正：对霜骨战斧分层隔离确认，末端最亮的横排来自 signature 冰片固定朝向与共同终点，并非烟雾本身。身份切面现沿主体轨迹分布、以局部切线定向，棱片改成首尾收尖的正确三角片；重击亮芯也沿末端切线收拢。烟雾卡片按局部轨迹在相机平面内转向，逐片错开旋角和长宽比，取消统一横放的画刷印记。动作 2196 项、世界网格 2355 项、动作 GPU 336 项检查通过。


烟雾扩展为九类表现：风流、落地尘浪、低沉冷雾、上卷热烟、短寿命血雾、细长魂带、收拢虚涡、短促离子残雾、缓升香烟。复用四张密度底纹，各类独立选择底纹、发射位置、运动、长宽比、寿命、颜色与低频 UV 输运，不宣称新增九张绘制贴图。所有卡片仍以主体为视觉中心，冷雾/离子雾更小更淡；重锤落点尘浪只在接触后产生。作用域覆盖每把武器的 profile 与原生空间烟雾 shader。


### 新烟雾原图 smoke-v3

现已新增九张独立 ImageGen 原图，不再以四张底纹代替九类烟雾：wind、dust、cold、heat、blood、soul、void、ion、incense。路径 `assets/combat/imagegen-mechanics/smoke-v3/`；逐张提示词与批次提示词集位于 `prompts/smoke-v3/`。所有原始 PNG 按 SHA256 原样复制，无裁切、重画或滤镜；明度转透明度在空间 shader 中执行。manifest 记录原始路径、哈希、1254×1254 原生尺寸、有效范围和提示词。`profile.smoke_source` 指定新烟雾底纹，旧 `density_source` 保留给连续弹道密度尾迹，避免将孤立烟团拉成不连续弹道。地震类角色强制选择扬尘原图。预览页附九张原图对照入口。

动作逻辑 2196 项、材质描述 1148 项、实际三动作 GPU 336 项通过；全量预览由同一生产空间渲染器生成。


### 贴图与动态网格配合（2026-10-19）

后续修正：该阶段只接入了弱灰度密度调制，不能等同于可辨识的刀光绘制主体。实际刀光 RGBA 刃面贴图由下文 blade-v4 接入。

释放主体现在使用独立的 ribbon_source 流动密度贴图。UV 沿逐把武器的路径展开，跨宽度保留清晰刃缘；热焰纵向原图先转为流动轴，再进行 UV 输运。镜像采样缓解非平铺原图的首尾断缝，尾段通过密度阈值逐渐侵蚀。主体纹理与碎石、身份轮廓、蓄力火花通过 UV2 权重分离，后者保持原有清晰几何，不被烟雾纹理覆盖。

弹体继续以实际绘制的弹芯配合原生空间轮廓和历史轨迹网格；尾迹也采用按原图方向采样的连续流动图，保留真实弹道与碰撞中心。九类孤立烟雾只用于粒子，避免把烟团硬拉成长尾。热烟、魂丝、轻烟按有效画幅比例竖直展开并向上输运；其余烟雾结合有效比例与各自物理扩散，末期做平滑侵蚀。

验证：动作逻辑 2196、世界空间 2355、弹体逻辑 297、动作 GPU 432、弹体 GPU 24 项均通过。新增 GPU 检查逐把将真实流动图替换为纯白，确认贴图会改变实际渲染像素，同时攻击网格完全不变。全量 69 个预览入口重新渲染。


### 可见刀光主体 blade-v4

此阶段的三张材质原图已由下文 weapon-v5 的逐把原图替代，文件保留用于历史对照。

新增三张真正的透明 RGBA 刀光展开原图：blade_edge_v4、blade_flow_v4、blade_fracture_v4，原样保存于 assets/combat/imagegen-mechanics/blade-v4/，提示词见 prompts/blade-v4/。它们是供动态曲面使用的横向展开纹理，分别提供锐刃、流体膜和断裂切面；不是已画成月牙的整张静态斩击。profile.blade_source 按武器材质选择，逐把路径与动作继续决定空间轮廓。

刀光 alpha 直接控制主体镂空和刃面，RGB 灰度控制笔触亮暗，原有程序亮芯不再填满贴图空白。降低释放碎片的亮度，命中碎片保留；避免零碎白片盖住刀光。flow_texture 仅保留晚期侵蚀辅助作用，不再用其弱调制冒充刀光贴图。

可复现的实际 GPU 分层对照：Godot_v4.7.2-stable_win64_console.exe --path . --script tools/preview_blade_texture_layers.gd，输出 build/vfx-3d/blade-texture-layers.png。左列以纯白图替换刀光原图，中列隔离实际刀光绘制主体，右列是完整效果；每行沿用相同攻击网格。动作 GPU 432、动作逻辑 2196 项通过，200 张原图审计无失败。

### 逐把专属主体 weapon-v5

使用内置 ImageGen 分别生成 52 张独立透明 RGBA 原图：肉鸽 600–647 共 48 把，加四把独立剧情武器 17–20。路径 `assets/combat/imagegen-mechanics/weapon-v5/weapon_<编号>_surface_v5.png`；完整提示词集 `prompts/weapon-v5/prompts.json`。逐张原样复制并保留 SHA256，52 张文件哈希互异。剧情 0–16 是同名武器入口，继承其对应原图；全部仍为 69 个预览入口。

每把按主题编写独立轮廓与内部结构：血膜、刺脊、折丝、镜面、封蜡、熔渣、地层、水幕、魂带、羽片、弹托、棱面与契页等。`profile.blade_source` 直接选择该武器编号的独立文件；原有逐把动作继续塑造空间路径，普攻、蓄力重击和战技有各自时序与几何。展开 UV 的两端跟随当前尾部和攻击前端，短普攻也能显示完整的贴图尖端，不会仅显示原图左半部。

远程释放与实际飞行尾迹也使用本武器的专属 RGBA 膜面；尾迹材质保留原图镂空，历史轨迹、弹体绘制主体和原生几何仍与真实弹道绑定。烟雾使用九类原图作为统一辅助层，不将烟雾也宣称为逐把独立生成。银月细剑原图边角有几个游离 alpha 像素，manifest 的 `render_ink` 仅修正运行时采样范围，原始 PNG 未修改。四把独立剧情武器的 family 分类同时纠正为短剑、法杖、大剑、镰刀。

原图总览由 `tools/preview_weapon_surface_atlas.gd` 在 Godot 中呈现，输出 `build/vfx-3d/weapon-surface-atlas-{0,1}.png`；预览页提供 52 张逐把原图和两张总览，并重新生成全部动态视频。验证：材质描述与逐把原图绑定 1357 项、三动作 2196 项、世界空间 2355 项、弹体逻辑 297 项、三动作 GPU 432 项、弹体 GPU 24 项均通过；252 张原图审计无失败。

实际战斗接入的 Compatibility 渲染检查 9441 项通过。预览捕获采用 `RenderingServer.force_draw(false)` 主动提交离屏帧，避免等待窗口自动重绘时挂起；最终全量视频以实际 Compatibility 空间渲染器导出。

后续主体可读性打磨：释放碎片数量按普攻/重击/战技限制为 5/9/12，命中仍保留独立碎裂爆发。碎片改成沿实际速度方向的两段收尖三角形，并以非等距位置发射，去除轨迹上的亮方片排列。冰/岩/镜面主体取消逐网格段交替宽度，让专属贴图负责破裂轮廓；灰色刃面的覆盖权重适当提高，保持原图 alpha 镂空。动作 2196、世界空间 2355、实际动作渲染 432 项通过，全部预览重新生成。

### 肉鸽实战尺寸与蓄力挂点修正（2026-10-19）

肉鸽 SubViewport 的 `socket()` 现在同时逆变换 tip/grip、charge_points 和每条 charge_paths；此前只有单点逆变换，界面缩放或居中会使蓄力描边偏离武器。3D 桥保留独立的武器轮廓路径，最多均匀采样每条 24 点，避免截掉武器末端和跨轮廓连接。蓄力粒子锚点使用实际武器 tip。

仅肉鸽配置：刀光主体宽度乘 1.55，近战释放轨迹乘 1.25，飞行弹体与拖尾主体乘 1.35；烟雾不跟随放大。视觉尺寸参数不修改战斗事件、伤害或判定范围；远程射程和光束终点保持权威事件位置。

回归：`tests/weapon_vfx_viewport.gd` 75 项；`tests/rogue_weapon_spatial_mounts.gd` 实际肉鸽 48 把武器、左右朝向、两种界面缩放，共 2073 项；均通过。实际实战蓄力/释放截图输出至 `build/rogue-spatial-{charge,release}-<weapon>.png`。
