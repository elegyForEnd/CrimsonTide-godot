# 《赤月遗书》RPG 装备系统

2026-10-16 · 已接入源码故事入口 `Start-Scarlet.cmd` / 标题页《赤月遗书》。

## 设计取向

用“底材决定操作、词缀决定倾向、暗金改变战斗选择、套装提供组合目标”的方式建立装备追求。装备始终服务于追缉、救援、拆契和共同终结的六幕故事；不能把任务机关变成可以用伤害跳过的血条。

沿用三位守望者各自的主手、护衣、护符，以及真实占格行囊。三栏迫使玩家在三件套与“两件套＋暗金核心”之间取舍，也适合当前单人切角色、两名伙伴跟随的操作。没有增加必须反复整理的十余个槽位。武器继续使用48种具体武器的动作、前摇、射程与图标，沿用角色武器适配范围。

本次完成32种随机词缀、30件暗金（18件角色武器、6件护衣、6件通用护符）、6套三件套、4种槽位差异晶石。这里是三人故事战役的完整装备循环；没有另加赛季、随机无限地城、重置首领或多人交易生命周期。

## 品质与实例

| 品质 | 色彩 | 随机词缀 | 特殊内容 | 取舍 |
|---|---|---:|---|---|
| 朴素 | 白 | 0 | 底材、阶级、强化与镶嵌 | 开局或材料来源 |
| 附魔 | 蓝 | 2 | 两种不重复的词缀家族 | 廉价、易理解 |
| 珍稀 | 黄 | 4 | 最多随机词缀 | 理想数值组合可挑战暗金 |
| 套装 | 绿 | 2 | 同一角色2／3件奖励 | 占用组合位置 |
| 暗金 | 橙金 | 3 | 固定身份、独有效果 | 选择流派核心，独有能力不可重铸 |

主手仍区分绯月、雪璃、鸦羽可用武器；护衣使用对应角色的底材；护符通用。不增加力量／敏捷门槛或鉴定消耗，新掉落可以立即读懂。装备阶级按获得章节1—6，不随当前角色或读档重新缩放。强化仍为+0—+5，品质不随强化改变。

每件保存独立 `uid`、底材、具体武器编号、品质、阶级、强化、原镶嵌状态、词缀ID与已掷数值、暗金／套装ID、晶石类型、来源、重铸次数与锁定状态。词缀数值按十分之一生成并保存；同类词缀不会在一件上重复，加载时不重新掷骰。

旧存档维持原值与原有品质；旧镶嵌的伤害+8／生命+12继续保留。新版晶石也保留这项基础镶嵌收益，在此之上添加分槽效果。不会把旧装备重新随机化，也不会因升级删除其物品实例。

## 六幕关卡与掉落内容

| 章 | 实际关卡／首领 | 装备倾向 | 关卡约束 |
|---|---|---|---|
| 1 | 雾桥礼拜堂、囚车护送、修院审判官 | 生命、药剂、恢复、护送、闪避 | 拆弩台仍是破防条件；先教生存 |
| 2 | 灰页书库、炉渠、焚书礼堂的审判长 | 战技、抗性、首领伤害、裂伤 | 三道宣判隔断必须逐一解除 |
| 3 | 矿坑、信站、维恩重盾 | 暴击、第三击、濒危保护 | 仍要引盾撞柱；首领免硬直 |
| 4 | 裁衣工坊、地下医室、外科示范厅 | 易伤、生命汲取、持续恢复 | 仍要关闭麻醉阀与承重机关 |
| 5 | 沉舟滩七人救援、潮盐工事、黑帆旗舰 | 位移、护盾、同行者减伤 | 潮水命中读取防护；仍要锁舵放船 |
| 6 | 彩窗工区、母晶、赤月王座 | 协同充能、首领增伤、抗性 | 护翼、雪璃稳晶、鸦羽断扣、绯月转刃全部保留 |

“异质抗性”是统一、可理解的装备属性：第一幕普通物理预警不受该词缀影响；后五幕的章节预警分别标记火／霜／毒／潮／血，统一读取该抗性。第五幕红潮也读取抗性。当前不要求玩家逐章重刷五套不同抗性装备。

| 来源 | 内容 | 去重与保底 |
|---|---|---|
| 普通敌人 | 30%主手；独立22%护衣／护符；独立12%四类晶石 | 主手连续3次没出，下一次必出；敌人收据保存成功与未掉落结果 |
| 探索宝箱 | 当前角色可用主手，至少附魔 | 原箱子开启状态持久化；不改地图或任务箱的语义 |
| 首领首次完整胜利 | 当前角色暗金主手＋当前章套装护衣或护符＋晶石 | 每个首领永久收据；换阶段、死亡、读档不重复发奖 |
| 章节结算 | 当前角色当前章套装一件 | 任务完成记录保证只领一次 |
| 营地打造 | 当前角色主手／护衣，70%附魔／30%珍稀 | 资源和占格检查成功才生成事务结果 |
| 章节套装配方 | 已到达章节的指定槽位套装 | 可补齐缺件，避免依靠无限刷首领 |
| 商人 | 原有固定装备货架、四类晶石、药剂和铁料 | 每章固定库存持久化；商店不出售暗金 |

普通敌人与宝箱有小概率暗金：第一幕0.8%／3%，后续2.5%／8%；套装累计阈值10%／22%，珍稀30%／55%，附魔75%／95%。这些是同一次品质骰的累计阈值，不相加。第一幕也可获得暗金护衣与护符。箱子剩余5%同样兜底附魔。

物品依次进入行囊→仓库→营地待领取箱。满包不丢装，不自动装备，不自动出售；稀有物品也遵循同一真实占格与事务规则。随机掉落面向当前角色，首领奖励适用于获胜时的操作者。

## 随机词缀与数值

基础加成继续由底材与阶级负责；词缀是附加量。攻击速度只缩短普通攻击总时长和释放前摇；不改变武器动作的伤害结算次数。战技冷却另算，协同技仍需积攒100充能。

| 类别 | 词缀覆盖 | 全身上限 |
|---|---|---|
| 输出 | 固定伤害、百分比伤害、暴击率、暴击额外伤害 | 伤害+60%，暴击45%，暴击额外+100% |
| 节奏 | 普攻速度、战技冷却、移动速度、协同充能 | 30%／35%／20%／50% |
| 生存 | 固定生命、生命比例、全伤害减免、异质抗性 | 生命+40%，减免30%，抗性50% |
| 续航 | 每秒回复、命中汲取、击败回复、药剂增幅 | 4生命/秒、6%、25生命、40% |
| 专攻 | 对首领、对低于30%生命目标、战技伤害 | 40%／35%／50% |
| 命中 | 裂伤、寒意、易伤、普通敌人硬直、普攻溅射 | 35%／35%／20%／25%／35% |
| 操作 | 闪避护盾、闪避后下一击、第三次普攻 | 50生命／60%／70% |
| 救援 | 同行者减伤、濒危额外减伤 | 30%／25% |

32条中有3条后期高基础版本，与对应基础词缀共享家族，不能在单件上重复。所有随机词缀逐一列出数值区间；后期才开放溅射、易伤和第三击，不让第一幕同时塞入全部机制。

核心结算：

1. 固定伤害进入战役原伤害公式，再乘全身伤害百分比。
2. 具体武器保留原威力／攻速／前摇；战技与协同保留原倍率。
3. 对首领、斩杀、已有易伤、相应战技／普攻增幅进入同一个加法增伤池，控制乘区膨胀。
4. 暴击默认1.5倍，再叠“暴击额外伤害”。
5. 最后读取首领机关减伤与阶段最低血线；结算实际掉血，再计算吸血和裂伤。
6. 同伴使用自己的装备与伤害。只有当前操作角色可通过自己的汲取／击败回复恢复共享生命条；AI不能变成无限输血来源。

受伤先扣原护甲整备与护衣的固定减伤，基础伤害最低5，再应用全身减伤、异质抗性、低于35%生命额外保护，最后由护盾吸收。同行者使用当前操作角色的护送减伤，最高30%；不会继承玩家吸血或无敌帧。

## 独有效果的实际规则

- 裂伤：普攻实际伤害的一定比例，在3秒内持续造成。保留最强一份并刷新时间，不叠几十层；重复结算也要服从首领机关减伤。
- 寒意：减慢移动2秒；首领只接受35%的减速效果，不改变预警读条。
- 易伤：首个命中施加4秒，后续直接命中受益；不会把无敌目标打穿。
- 溅射：普通攻击主目标周围180基础单位内的可见次目标，每次释放最多吃一次，不穿墙，不重复击中已被主攻击命中的目标。
- 硬直：只对普通敌人触发0.4秒；不打断首领的机制与预警。
- 闪避护盾：持续3秒，重复闪避刷新而不叠加；切人清除，不能借高防护角色给另一位存盾。
- 闪避反击：下一次命中的普通攻击消费一次；挥空不消费。
- 第三击：每第三次命中的普通攻击获得增幅；多目标只累计一次，挥空不计数。
- 汲取：按实际掉血计算，每次命中最多恢复3生命；机制保护期间没有实际掉血便没有汲取。
- 持续伤害和溅射不递归触发暴击、裂伤、汲取或其他命中效果。阶段开始／死亡重试清理临时状态；完整物品、奖励和去重记录保留。

## 晶石与铁匠

| 晶石 | 主手 | 护衣 | 护符 |
|---|---|---|---|
| 赤棱晶 | 裂伤12% | 濒危减伤8% | 暴击5% |
| 霜心晶 | 寒意12% | 抗性12% | 战技冷却7% |
| 羽纹晶 | 攻速7% | 移速5% | 闪避反击18% |
| 导光晶石 | 协同充能12% | 同行者减伤10% | 回复0.6/秒 |

每件只有一个镶嵌位置，80银币＋1对应晶石。可以替换，旧晶石消耗；基础伤害+8／生命+12不重复累加。晶石继续使用原素材图标，不新增待导入贴图依赖。

定向套装配方每件为 `180＋章节×60` 银币、`10＋章节×3` 铁料、1导光晶石。可选择已经到达的较早章节与指定槽位。打造前先检查成品完整占格，材料不足或放不下都不扣款。

附魔、珍稀、套装可以重铸所选词缀的数值；家族与其他词缀保留。费用 `100＋阶级×40＋已重铸次数×80` 银币、`5＋阶级＋次数×2` 铁料，每件最多20次。可能得到更低值，界面展示区间和次数；暗金独有能力不提供重铸。

锁定装备防止出售、分解、重铸和替换晶石；仍可正常装备、移动、卸下和强化。分解沿用确认窗。商店回购恢复原UID、原词缀、原晶石和强化，不生成替代品。

## 操作与可读性

- TAB行囊：五档颜色、原武器图标、占格、强化等级与“锁”标记。
- 选择物品→“词缀／比较”：滚动查看完整属性、词缀范围、独有说明、套装两档效果、来源；按适用角色比较换装后的全身词条及上限，包括套装失效的损失。
- 营地铁匠：“晶石／重铸／锁定”打开对应操作；“章节套装配方／遗物图鉴”展示六幕来源和30件暗金，可定向补齐套装。
- 人物页实际冷却读取装备；战斗HUD显示剩余护盾，普通敌人血条旁显示裂伤／寒意／易伤。
- 未选择物品时，词条入口打开装备图鉴；没有隐藏的装备评分自动替换操作。

## 实现与验证边界

数据源 `tools/build_rpg_equipment.py` 生成 `resources/rpg_equipment.json`。规则 `scripts/rpg_equipment.gd`；库存事务 `story_inventory.gd`；战斗临时效果 `scarlet/equipment_combat.gd`；主战役接线 `scarlet/campaign.gd`、`combat.gd`；显示 `story_items_ui.gd`、`story_item_grid.gd`、`scarlet/screen.gd`。

存档兼容保留战役version2／items_revision1，新装备另带affix_revision1。加载校验字段类型、词缀数量／ID／区间／重复家族、暗金和套装身份、角色底材、晶石及重铸次数，随后将JSON数值还原为规范类型；不可通过删除版本字段把含词缀的损坏装备伪装成旧装备。

新增自动测试覆盖270组章节×角色×槽位×品质生成、全部暗金、存档往返、套装独立、异常数据拒绝、事务原子性、真实战斗效果、六位首领机制、奖励去重、实际UI操作及渲染截图。全战役回归覆盖现有主线与分支，但使用测试伤害与站位注入，不能代替玩家连续动作通关。当前数值是有上限、可继续调校的首版；尚未声称完成长期真人平衡、所有武器DPS一致或发布包重新导出。

完整装备清单可在游戏的遗物图鉴查看；对应的暗金名字、独有效果及数值由同一份JSON提供，避免文档与运行数据形成两套规则。
