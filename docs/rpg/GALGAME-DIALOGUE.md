# 灯下的回声 · 剧情对话 v12

故事模式的章节、营地交谈、结局选择和结局回顾接入 Galgame 式阅读。背景保持当前真实地图，隐藏战斗 HUD 和地图姓名标签；透明立绘分左右站位，说话者高亮，其他人物退暗，0.22 秒过渡。底部哥特材质对话框和独立姓名牌使用原有原创九宫切片，选择、自动播放与回看都是实际 Godot 控件。

## 操作和入口

- 正式游戏：根目录 `Start-Dialogue-v12.cmd`，在标题进入故事模式。
- 直接体验：`Preview-Dialogue.cmd`，进入雷霆要塞的岑烬交谈，使用独立 APPDATA 和临时进度，不保存战役或阅读记录。
- 点击空白处、空格或 Enter：先显示当前全文，再进入下一句。
- 自动按钮 / A：全文显示后等待再翻页；已读快进按钮：只跳过读过的页，到未读内容立即停止。
- 回看按钮 / L：查看最近 180 条对话，打开时暂停打字和自动播放。Esc 先退出回看，再收起对话。
- 对话末尾出现服务和任务选项；自动与快进不会选择选项。救援女王仍要求战前个人线及支线准备。

## 实现和边界

`story_dialogue_data.gd` 保留已有 73 个任务、王国前史和三个结局的完整正文，按原有引号及段落拆页，每页最多 108 字。只有明确署名的话语才指定说话者，未署名保持旁白；不会凭邻近名字猜说话者。后续可直接提供结构化 `speaker/text/left/right/actor` 分镜数据，无须修改阅读控件。雷霆要塞岑烬的开场交谈单独编排八段分镜。

`story_dialogue_ui.gd` 只管理显示、阅读记录和显式选项。`story_screen.gd` 负责暂停、调用营地服务、任务日志、交易、锻造与仓库。任务完成仍由 Campaign.complete 发奖励，读故事和回看不会重新完成任务。阅读标记以正文散列存入对应战役文件旁的 `.dialogue-read.json`，不改变战役存档结构；保留最多 4096 个标记。

继续使用现有三位主角、六种营地 NPC 岗位及女王立绘。其他营地的人物沿用现有岗位美术；本轮未制作 36 位 NPC 的独立立绘、表情差分、眨眼口型、剧情 CG 或整篇语音，也未将全部旁白重新改写为台词。当前是可玩的对话演出与阅读系统。

## 发布与复建

`dist` 中四个文件需同放：

1. `CrimsonTide-ForwardPlus-v12.exe`
2. `CrimsonTide-Dialogue-v12.pck`
3. `CrimsonTide-Combat-v11.pck`
4. `CrimsonTide-ForwardPlus-v9.exe`

先挂载 v9 场景底包、v11 GUI/战斗补丁，再挂载 v12。v12 仅包含三个对话脚本的编译资源和重映射，不发布未完成的 3D Boss 模型。现有 v11 入口继续指向旧版本。

复建：`python tools/build_story_dialogue_release.py`，或传入匹配的 Godot 4.7.2 Windows release 模板路径。工具临时追加导出预设并在 finally 恢复原文件，通过官方导出器生成 `.gdc`，白名单提取三组脚本与 remap，再嵌入引导包。不能只往旧包添加同名 `.gd`：旧导出 remap 会继续加载旧字节码。

## 验证

`tests/story_dialogue.gd` 验证完整正文、不猜说话者、六幕 NPC 路由、实际鼠标与空格、自动/快进/回看、显式选择、治疗、缩放后的商店入口、未准备救援拒绝、奖励幂等、阅读记录恢复与退出清理。GPU 运行加 `-- --capture-dialogue`，截图写入 `build/galgame-*.png`。

Forward+ 和 Compatibility 分别 214 项通过；无头 210 项通过。原战役 180 项、故事集成 12 项和原任务UI最终34项通过，最终各组合计864项。发布 EXE 在两种渲染器下均实际进入新界面，读取八页岑烬分镜并生成截图 `build/galgame-native-v12.png`。Forward+ 退出仍有项目既有的七个 Texture RID 警告；本轮没有长时间跑分或 4K60 验收。
