# 赤月遗书 · RPG敌人与首领制作

8种小怪、6位章节首领、2位可选首领已经接入源码版。每个敌人均有待机、蓄力、出手3个独立绘制姿态，共48个姿态；使用原生尺寸透明图片，运行时增加呼吸、移步、出手位移与受击震动。34个Boss招式和13个小怪招式使用实际判定与预警。
