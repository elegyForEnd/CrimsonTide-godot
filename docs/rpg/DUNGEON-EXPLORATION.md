# 副本探索与地形重做

本文件记录v6制作。最新v7已替换统一15房间骨架、固定四段高差和默认围墙，30个副本改为22种空间类型，见[DUNGEON-IDENTITIES.md](DUNGEON-IDENTITIES.md)。

2026-10-10。针对副本空旷、范围偏小、孤立高台和方形边界，重做六幕的30个室内区域与19个室外区域。营地、地图ID、73个任务及层间目的地保持原有结构；本轮没有导入参考游戏素材。

## 本地参考实际读到的内容

只读检查用户指定的两个安装目录，工具为`tools/inspect_reference_dungeons.py`。读取旧包Levels、LvlMaze、LvlPrest以及25个DS1样本；读取重制包33个HD场景JSON，包括地窟、墓室、高塔底层主题场景、地下监牢、地下陵墓与上下层过渡。统计、校验值和资源依赖在`reference-dungeon-inspection.json`，原始JSON只存在忽略的output目录。

旧包的迷宫配置将房间数量、房间尺寸与特殊房模板分开：抽样中地下监牢为12、14、16间，地下陵墓为12、14、16、18间，相关房间模板为12×12；墓室及高塔地下层使用8×8模板。这里是配置记录，不能把逻辑格数换算成现实米数，也不能把Levels中的200×200直接解释为实际生成的可走面积。洞窟方向模板另有入口、主题间、上下层与特殊房。

重制版样本将岩壁、拱门、墙脚、灯具、装饰、遮挡与物理拆开。高塔主题样本cryptcountess1/2含857/681条实体；这不是857/681个交互物体。Transform的局部Y还包含墙顶、吊具和装饰高度，不等于每个值都是可行走地面的高度。可借鉴的是空间构造与功能分组，不能据此声称已解码或复现参考引擎。

## 本项目的实际实现

- 30个室内区域使用80×108米包络，每区15个命名功能空间。真实可走面积约2600—3580平方米，包络内部保留不可走的岩体、设备井及结构核心，绝非整张80×108米平地。
- 六套房间组合有各自中心位置、连接图及轮廓；同幕按关卡调整房间尺寸、支廊和朝向。主线、主题大厅、奖励侧室、死路和环路同时存在。原来的地图层数与入口目的地不变，未新增一座五层高塔。
- 每区超过100处实体地编：壁龛、柱基、门户、石棺、工具桌、货物、断柱、碎石及工作灯。大型中心设备留有绕行空间；各幕采用自己的炉具、星仪、温室、面具柜、船体或圣物设施。新增34个原创Blender模块，权威源文件为`art/story-environment/dungeon-master.blend`。

最终布局共3471处副本道具摆放，新模块共58944个三角形。建筑仍使用各幕先前制作的独立结构与PBR，这次新增的是局部细节与房间组合，未把全部建筑和材质重做一遍。
- 每区布置分房间敌群，深入路径也有战斗；四个奖励宝箱分配到侧室。宝箱原前两个索引继续保留，追加第三、第四个。旧存档保留开箱、任务和传送状态，进入新布局时在新入口出现。
- 取消室内孤立矩形台地，改为四段贯通空间的高程变化。建筑副本的50厘米进深台阶、踏步、立面与人物高度共用一份数据；天然洞道使用缓坡和轻微岩土起伏。四段分别通向低层、过渡层、上层及深室，未实现上下重叠的双层桥。
- 19个室外区域使用不规则外轮廓、侵蚀坡脚、岩脊和保留的连接口；旧台地改为700厘米宽的坡肩，并加入两组次级地形起伏。地形网格、可走区域、导航和探索图一起修改，小树仍不阻挡。
- 中央不可走区域有实体表现：天然洞室保留高岩体，建筑副本保留下沉结构底部。对照检查避免将这些核心区域误填成地板。

## 制作与同步契约

`resources/story-exploration.json`是房间、轮廓、空洞、路线、高程、道具和敌群的共同数据源。`story_exploration_art.gd`提供运行时空间与高度，`story_exploration_environment.gd`生成地面、连续墙脚、洞壁和灯光。编辑布局后必须更新对应TSCN/SCN、兼容缓存，并重烘静态地面的GI。不能只改变碰撞而沿用旧可见地板。

`tools/author_story_exploration.py`为首次制作工具，运行时不依赖Shapely；数据存在时工具拒绝覆盖。原Blender源文件仍保留，新模块局部导出用`export_story_models.py --source=art/story-environment/dungeon-master.blend --assets=...`。

`Build-Exploration-Scenes.ps1`会明确替换49个生成场景，运行前应保存手工场景编辑。`Bake-Exploration-Scenes.ps1`支持按幕烘焙。`patch_story_exploration_centres.gd`和`patch_story_exploration_geology.gd`只用于本轮动态部件接入；不能用于悄悄替换已烘焙静态遮挡体。天然洞壁使用按面投影UV，避免顶部把竖直岩纹拉成条带。

曲折轮廓的点内判定采用半开射线与双精度标量计算，避免复杂凹洞多边形在顶点附近误判可走区域。导航网格留36逻辑单位的安全余量，人物本体为24；模型门户脚座有独立占地，门洞中间可走。

自动烘焙临时隔离编辑器的场景恢复列表，完成后还原原列表；每场保存并关闭，避免55个编辑器标签同时恢复、占用内存并拖慢后续烘焙。所有修改都在项目缓存和自有制作工具内，不涉及参考安装目录。

植被不直接保存无头渲染器的MultiMesh缓冲。`story_ground_cover.gd`保存明确的网格和CPU变换，进入场景时构建真实实例缓冲，制作/兼容打包前清空GPU数据；`patch_story_ground_cover.gd`验证原植被没有GI用户后更新五个第一幕室外缓存。这样避免无头序列化中的无效浮点数把植物拉成覆盖整个画面的平面。草丛按噪声斑块聚集、避让道路，地面蕨叶使用小尺度。

为支持新增墙体遮挡部件，Forward+着色器实例参数缓冲区从默认65536字节调到1048576字节；Compatibility启动仍保留。界面、角色精灵和战斗机制继续使用原系统。

## 验收边界

本轮检查包括真实移动到全部功能房、目标与宝箱，洞壁与地面轮廓一致、空洞未填、两种渲染器截图及更新后的光照资源。具体结果以TEST-REPORT最后一节为准。

本轮加强了空间与地编，仍未达到商业重制版逐件雕刻和材质精修的程度。部分设备与道具跨关复用，人物/怪物/宝箱仍使用已有资产；没有新增独立谜题、五层高塔剧情或专属Boss动作。4K截图证明输出分辨率，不证明4K60；长时间跑分继续暂缓。
