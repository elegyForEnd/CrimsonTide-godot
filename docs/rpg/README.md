## 本版依据

背景优先依据 [PV提示词](../../pv/tishici.txt)，并落实用户追加的两条流程要求：开局在营地，向画面下方走进入第一张野外地图；每个大关卡有独立营地和可交互NPC。

PV中的人物与画面事实是本稿的固定基础：绯月白发红瞳、持赤晶单手剑，没有王冠和羽翼；雪璃浅蓝发蓝瞳，以教堂提灯施展守护；鸦羽深紫发紫瞳、高马尾、使用长刀。血潮女王高挑，持王冠与长赤晶剑，具有恰好六片彩窗刃翼；女王与绯月是两个不同人物。三人深入边境、获得血晶、选择继续前进、相互掩护、与女王交锋、释放协同奥义，最后迎来黎明，建筑仍是废墟。

PV的镜头人数、无对白、无字幕、时长和画风要求是视频制作约束，不作为禁止游戏剧本对白或禁止营地NPC的指令。引用这些段落的意图是继承世界背景、角色辨识和关键故事画面。

女王的历史、血潮运作、地方NPC、任务、角色经历和结局代价是本次新增创作。血晶按PV作为月辉矿物展开。墓煜不作为主线第四位守望者插入三人终局。

## PV画面与长篇故事的对应

| PV段落 | 故事中的落实位置 |
|---|---|
| 血月降临、王城与女王 | 世界前史；第六幕大教堂女王出场 |
| 三位守望者集结 | 序章营地庭院与南门出发 |
| 石桥、湿地、圣物箱、血晶 | 第一幕石桥与废弃礼拜堂；第五幕潮湿环境扩展 |
| 撤离灯塔与血色教堂之间的选择 | 第一幕风险教学；第五幕不可回避的主线抉择 |
| 鸦羽开路、绯月突进、雪璃保护 | 第一幕合作教学；第六幕战斗配合回收 |
| 女王环形预警与绯月迎剑 | 第六幕女王第一阶段 |
| 三人奥义、玫瑰窗光纹 | 第六幕终局解决血潮的核心动作 |
| 赤云散去、三人看向黎明 | 终章共同结局画面；废墟不被魔法重建 |

PV是凝练的预告片，以上对应不意味着把八段镜头机械延长成八个关卡；完整战役在这些画面之间增加当地人物、探索和因果。

## 交付边界与参考核对

武器与技能表现最新实现：[COMBAT-FINISH.md](COMBAT-FINISH.md)，覆盖故事、闯关、搜打撤；新增命中材质、运动碎屑、真实弹体尾迹、技能收尾与短时光源，保留旧数值与任务。

本目录保留设计稿与长篇剧情，另提供基础可玩实现。体验时长和工期仍为待检验目标。故事入口使用主场景独立的 `story` 页面，未加入TideSession的远征生命周期；TideSession模式值仍为 `expedition` 与 `roguelike`。

提供的本地游戏目录已只读解析地图模板、地块库和关卡表，详细数值见地图研究；未运行它，也未声称逐关实玩。章节任务与路标规则另用[官方任务说明](https://classic.battle.net/diablo2exp/quests/basic.shtml)及[官方地图说明](https://classic.battle.net/diablo2exp/maps/)核对。计划正文不提参考作品名称。
