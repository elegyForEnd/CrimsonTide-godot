# 武器与技能表现升级 · v11

2026-10-11。故事、魔境闯关、三日远征共用新命中与收尾层；普通攻击、实际战技、释放挂点、弹体、命中及消散分别组织。源代码入口仍是游戏启动.cmd；发布入口为 Start-Combat-v11.cmd。

## 已接入实际游戏

- 现有具体武器原画与配色保留，刀光增加渐进揭示。近战/枪口/弓释放在18毫秒达到完整接触轮廓；法术起势35毫秒。揭示只裁覆盖区域，不拉伸贴图、不移动接触点。蓄力跟随武器，释放后固定世界位置。
- 六格原创RGBA图集分别提供金属火花、低亮烟尘、赤晶碎片、冰晶、余焰和魂光；6—11条独立碎屑用速度、重力与短尾迹运动。命中亮点先熄灭，尘雾与元素碎屑后消散，普通命中生命周期0.65秒。额外光层透明度受限，保留怪物和危险预告的可读性。
- 连锁电弧沿真实起终点细分、短促跳动；范围技能使用逐渐外推的断续压力波，范围取真实事件。没有额外伤害判定或虚构的飞行弹体。
- 普通圆斩保持角色圆心与真实reach，不再因精灵刀刃长度放大。锤击保持已有下砸原画和不同平面。其他近战刀光与判定范围的一致性仍有既有缺口，见下面的验证边界。
- 真弹体附带只用于表现的fx_id，三种玩家弹体生成入口都写入，同步快照保留它；尾迹记录真实位置，16毫秒采样、最多10点、残留130毫秒，600逻辑单位以上跳变清历史。切图/开局清理残留。旧快照没有fx_id时只跳过新尾迹，原弹体继续显示。
- 故事新增独立combat_event信号。玩家攻击、Q技能、R协同奥义、伙伴攻击和真实命中触发图像与粒子，取代玩家攻击的纯线条绘制；霜术命中连线只连到实际受击目标。原有伤害、冷却、治疗、装备、任务和存档规则保持。特效动画在暂停面板期间可完成消散，不重播或补发伤害。
- 故事与搜打撤的3D场景新增最多8盏短时无阴影灯，不进入烘焙GI；故事按map.height_at抬到真实地面上。闯关仍为既有2D场景，用独立加色光层。场景内特效主体仍沿既有Canvas层绘制；未全面重做3D深度遮挡。
