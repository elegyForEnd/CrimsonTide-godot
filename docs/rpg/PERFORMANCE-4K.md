# 4K验收记录

本次验证机：RTX 3080 Ti 12GB、i5-13600KF、约64GB内存；Windows、Godot4.7.2、Vulkan Forward+。

输出3840×2160，3D内部比例0.67（FSR2），UI保持输出分辨率。测试关闭垂直同步和60帧上限，以测量实际帧时间；发布版上限60帧。

`tests/story_4k_benchmark.gd`运行三轮行走与三轮持续战斗，每轮600秒，开头12秒初始化不计入热运行统计。行走包含实际地图、人物、敌人、相机、UI、区域加载和路线判定；战斗使用三人小队、持续补充约24名敌人，固定等级并补充玩家生命以保持测试负载。基准不保存到玩家存档，也不改变游戏战斗规则。

原始结果在 `build/story-4k-benchmark.json`；包含均值、P95/P99、最慢帧、超过50ms的帧数及CPU/GPU渲染耗时。首次进入营地和通过入口进入洞窟单独记录。`build/story-gpu-samples.json`为整张显卡占用，包含其他程序，不能等同于游戏单进程显存。

用户要求优先处理地面闪烁并暂缓长测，已停止首轮约4分钟的运行；未完成六轮验收，不能据此宣称最终稳定4K60。工具和命令保留，待继续验收时使用：

```powershell
& tools/Run-4K-Benchmark.ps1 -Duration 600 -Runs 3
```

图形验证同时覆盖实际4K截帧、GI资源绑定、局部雾开关、屋顶过渡、独立岩石材质与当前植被网格。传统营地、远征攻击／奥义、104个Boss招式四阶段、肉鸽页面和特效各有GPU验证。Compatibility使用移除体积雾和实例参数的独立缓存，地图与逻辑高度共用；不能把兼容模式的表现当成Forward+高画质。
