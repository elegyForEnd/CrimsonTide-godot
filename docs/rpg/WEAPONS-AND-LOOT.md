# RPG 武器、动作与掉落

赤月遗书读取闯关模式的 48 种武器目录、手持动作图集、武器图标和特效素材。绯月可用单手与重武器，雪璃可用法杖，鸦羽可用单手与远程武器。原有装备及存档仍可读取，缺少武器编号的旧装备使用对应角色的默认武器。

每件新武器保存 `weapon_index`，装备后同步站立、行走、疾跑、闪避、攻击与战技动作。普通攻击读取武器的攻击间隔、前摇、威力和射程；伤害在前摇结束时结算一次。角色原有 Q 技能与 R 协同技保留。RPG 成长与品质继续使用战役自己的规则。

探索宝箱必定提供一把当前角色可装备的武器，至少为附魔品质。普通敌人死亡有 30% 概率提供武器，连续三次未掉后下一次必掉；掉落阶级随章节提高。获得武器时播放浮起的图标、名称与光圈，并提示存入位置。

武器自动进入行囊，行囊满时进入仓库，二者都满时进入营地待领取箱。宝箱打开状态、怪物掉落收据与未掉落计数均随战役保存；读档或重试同一遭遇不会重复领取相同小怪的武器。

验证：`tests/scarlet_weapons.gd` 覆盖装备、动作、前摇、掉落、满包、存档及重试；`tests/scarlet_weapon_visual.gd` 遍历 48 种武器的挂点和特效，并可使用实际渲染器生成截图。另运行战役、规则、入口及原背包回归检查。

特效的相机投影与武器挂点在进入界面绘制层时转换为局部坐标，避免主界面缩放、居中或留边造成二次缩放与偏移。`tests/scarlet_vfx_alignment.gd` 覆盖三种界面布局、三档镜头缩放、四个攻击方向及近战/重型/远程/法杖挂点，并验证出手特效的位置。角色脚下不再绘制常驻金色定位圈；交互提示与敌人攻击预警保留。
