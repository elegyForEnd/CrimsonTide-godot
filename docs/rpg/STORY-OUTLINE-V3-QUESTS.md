## 一、故事主线和玩法结构

绯月收到五年前被她登记为“已撤离”的少女露诺的求救信。追查之后，三人发现王庭的“晨归计划”确实能恢复日照，代价却是抽走边境三地的结界，让来不及撤离的人承受最后一轮血潮。绯月当年的撤离签名被篡改用途，成为地方同意弃守的凭据。

三人先救人、再找证据，最终必须证明另一套释光方案可以执行。一路调查也揭开她们自己的责任：绯月曾离开仍有人等救援的村子，鸦羽隐瞒过可能救人的退路，雪璃的老师曾替她同意征用晨火。她们不能只揭发女王，还要把自己不愿公开的部分交给被救者判断。

六章依次解决：**救谁 → 谁决定牺牲 → 替代方案是否成立 → 为什么曾失败 → 如何承担新失败 → 谁来决定共同的未来。**

六位章节大 Boss 为葬钟主教、余烬司祭、誓约猎王、镜墓纺女、冥潮守门者、血潮女王。它们提前参与本章矛盾，第六个主线任务收束本章危机。普通关卡安排巡逻、野兽和精英战即可，不按任务数量堆 Boss。

## 二、开场：先让玩家看到一场发生中的事

### ADV 序幕《最后一班车》

建议约 3—5 分钟，以背景图、人物立绘、局部插画、音效和少量镜头运动完成。不要求先制作完整动画。首次进入新战役自动播放，允许推进文字、查看回顾与跳过；跳过后展示简报，再交还控制权。

**场景一：五年前，静钟村外。**

黑屏先听车轮、雨和有人敲打车厢。画面亮起时，绯月扶着受伤的孩子上车。村口最后一盏灯正在变红。军官摊开一张被雨浸湿的表格，要求她确认这一批人已上车。

军官：“签这里。车不能再等了。”

绯月：“西边还有人。你们下一趟什么时候回来？”

军官：“下一趟的事，由后面的人负责。”

绯月望向车厢。伤员正在发冷。她签名，手停在“本批撤离完毕”几个字旁边。镜头不隐藏她看清这句话的事实，也不提前揭示文件后来被如何使用。

车开动。一名少女从暗处追出来，手里举着一只没点亮的门灯。绯月回头，听见她喊了一句，车轮声盖住后半句。

**场景二：现在，雷霆要塞。**

同样的敲击声变成阿梨敲门。绯月醒来，桌上是修过多次的赤晶剑。阿梨递来静钟村的新信。

阿梨：“信上说，一定要交给上次带车来的人。”

绯月看见署名“露诺”，立即去翻旧撤离册。露诺名字后的完成栏，有她自己的签名。

玩家可在此暂停查看信件插画和旧册，属于 ADV 阅读交互，不要求操作角色找三个发光点。

**场景三：不是好兆头的晨钟。**

钟声响起。窗边七年没有开花的植物突然舒展，短暂开放，随后花瓣结出细小赤晶。远处守卫欢呼“天要亮了”，雪璃却把手放在窗前，发现那道光没有温度。

雪璃：“先别碰它。”

鸦羽在院里望向南方：“这不是要塞的钟。”

**场景四：决定出发。**

岑烬想先安排另一支巡路队。绯月说自己认识村路，主动接下。雪璃注意到她一直攥着信，但没有当众追问。鸦羽把地图转向她，指出桥头最后一处仍能返回的灯标。

岑烬：“你是去找人，还是去确认名单没错？”

绯月没有回答。她将信展开，给另外两人看背面：

> 明天会天亮。他们说，不在名单上的人不用等。

**场景五：回到可操作营地。**

镜头从三人立绘淡入雷霆要塞庭院，HUD 出现，日志显示“找到写信的露诺，确认静钟村状况”。玩家从这里自由整备、交谈，再从南门出发。世界前史、六地名称、月核原理暂不讲解。

开场留下三个明确疑问：露诺为何没撤离？名单外的人将遇到什么？眼前的“黎明”为什么让花晶化？玩家的第一个目标是找人，后续调查再逐步扩大故事范围。

## 三、第一章《钟响之前，没有弃民》

**本章事件：**寻找露诺，救出名单外的村民。绯月试图把旧签名藏在寻人行动后面，露诺却带着当年的门灯出现。她并不急着指责绯月，先要求三人帮她把藏起来的孩子带走。

主教赛芙琳从前半章就通过巡夜广播、登记名单和热汤分配出现。她确实维持着村庄结界，也正在以名额筛选谁值得留在结界内。她的最终封存迫使小队进入修院。

个人线的精细参数、白匣医疗记录和主线已有应急接口共同构成女王救援准备。终局前清单必须直说缺什么、去哪补，不使用隐形好感分；具体检查键在实现时统一替换旧条件。

## 十二、任务制作契约

1. **剧情事件与可玩目标分开。**任务注明“看演出、拿证据、开设施、护人员、解遭遇”的类型；照湾死亡等固定情节不包装成能赢却实际上必输的操作。
2. **每项主线有可检验结果。**护送检查人员到安全站，潜入检查文件已拿且已离开，机关检查输出状态，Boss 检查遭遇解决；不以站到末端标记自动代办全部过程。
3. **失败可续接。**被发现转普通战斗；护送倒下回最近安全站；机关错误给现场反馈可重调；不能因一句选错对白永久卡主线。查证依据都在可访问场景中。
4. **先做过的行动能计入。**证据、救援、设施与任务奖励用稳定 ID 存档。线索进独立线索袋，不能出售、随机丢失或被材料消耗。跨任务使用同份证据，不要求反复开箱。
5. **少量 Boss，有充分预告。**六位章节 Boss 在前几个任务通过命令、面谈、环境后果出现；五位明确可选 Boss 独立开放。普通任务用不同目标与环境形成玩法差异。
6. **ADV 为行动服务。**开场完整引出悬念；章节开闭幕有短演出；行进用短对白；长证词、前史自愿展开。看完或跳过都更新“已经知道什么、下一步为什么去那里”。
7. **结局代价说明一致。**晨火不可再生，备用普通灯不推翻熄灯结果；七日按阶段推进，自由探索不暗耗时间；终局入门前备份，战后世界与结局收藏分开。
