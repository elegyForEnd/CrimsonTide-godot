# 赤月遗书 · 现场调查与机关玩法

2026-10-16。当前源码入口为根目录 `Start-Scarlet.cmd`，标题页“故事模式 · 赤月遗书”也使用相同实现。

89个物理任务节点、267个操作部位，覆盖全部33处实物调查、54处常规机关，以及王城侧门与战后拘留区两处条件操作。剧情对话、证据辨析、护送、试航和首领继续使用原有流程。

## 操作

走近现场按 **E**，打开带物件近景示意图的操作面板。鼠标点击部位，或按 **1／2／3** 选择。调查可任选顺序；机关必须先处理支撑、受力或准备步骤，再执行后续操作。错误顺序会提示原因，不会损坏证物。

| 类型 | 实际操作 | 例子 |
|---|---|---|
| 实物调查 | 选部位后按住E或操作按钮，读出三处独立细节 | 透光账页、泥印、军库箭簇、血晶、潮痕 |
| 持续操作 | 按住E或操作按钮；松开后尚未固定的进度缓慢回落 | 推车、移动柜体、清理落石、交还药箱 |
| 张力控制 | 按住收紧，在青色区间松开；过紧会回弹重试 | 桥索、救生绳、捕猎索、缆弩 |
| 角度微调 | A／D或左右微调按钮移动指示线，进入青色区间后按E确认 | 提灯照明、舵杆中轴、手套针脚 |
| 时机校准 | 指针进入青色区间时按E或点击确认 | 蒸汽阀、门锁、升降架、药剂试制 |

三处都完成后，点击“收入线索袋／确认收尾”或按Enter才提交当前任务节点。调查提交后仍会显示原先的证据记录剧情，证据辨析继续依赖真正获得的事实。已完成部位可点击回看。

Escape或“暂离”返回现场。已固定工序与已查明部位按节点ID保存；未完成的动作需要重新稳定。重新进入及真实存读档后继续剩余工作。可勾选宽松校准，扩大安全区，放慢自动指针和绳索收紧速度；无需额外材料，也没有倒计时。

## 场景表现

十类代码构建的3D物件：工作台、文书台、痕迹测尺、医药箱、晶体座、提灯、绳索架、阀轮、门锁和柜车。使用原地图的地形高度与可达地面落位，替换这些任务原先统一的蜡烛／图标物件。

阀轮随操作转动，门扇解锁后打开，柜车移位，绳索受力改变，提灯发光并轻摆，血晶浮动，医药箱盖启闭。提交产生短时碎光与现场文字反馈；已处理物件回访时按保存状态呈现。近景面板包含对应动态示意图、观察透镜和部位连线。所有表现只读取规则，不结算任务或奖励。

## 实现与内容维护

- `tools/build_scarlet_fieldwork.py`：逐节点工序、逐证物观察结果，生成 `resources/scarlet/fieldwork.json`。增改剧情节点后依次运行原剧情生成器与本生成器；缺少机关或证物设计会报错。
- `scripts/scarlet/fieldwork.gd`：合法目标／距离／角色校验，三种校准，部位进度及提交权威。输入的坐标与描述由当前剧情节点重新解析。
- `fieldwork_ui.gd`、`fieldwork_art.gd`：近景交互与动态示意图。
- `fieldwork_props.gd`：真实地图物件、操作动画、回访状态与完成碎光，由`world.gd`调用。
- `campaign.gd`：新增可选存档字段`fieldwork`和`fieldwork_relaxed`；保持version2／scarlet-1，旧档补默认值。验证部位去重、范围、工序顺序及完成标志，JSON读回后恢复整型ID。
- `screen.gd`：现场面板、输入隔离、日志工序提示、完成文字。交互期间不能移动、切人、攻击、闪避或旅行；先退出现场面板即可恢复。
- `render_campaign.gd`：这些物件交由新物件层绘制，避免同时生成原来的通用任务摆件。基础地形、相机、角色与战斗渲染继续复用。
- `export_presets.cfg`：明确包含新增玩法JSON；本轮没有重新导出发布exe。

调查稳定时间0.85秒，普通工序1.15秒；未固定动作松开后每秒回落0.75。普通安全区半宽0.13，宽松半宽0.23；自动指针速度1.7／0.9，绳索收紧速度每秒0.36／0.24。调整角度的速度为每秒0.42。角色交互距离仍为105。

## 验证

`tests/scarlet_fieldwork.gd`覆盖全部89个物件的真实完成路径、三种校准、错误顺序、未选部位长按、过紧重试、显式提交、重复提交、离开续接、真实JSON存读档、旧档、非法数据、角色与距离校验。`tests/scarlet_campaign.gd`通过规则API操作全部部位，继续验证四组主线分支与全部支线。

`tests/scarlet_fieldwork_visual.gd`通过实际故事入口和真实部位／提交按钮，检查键盘Escape、面板布局、十类近景、场景物件与持续状态，输出`output/fieldwork-*.png`。自动脚本会设置角色站位；不等同于真人全程动作通关或长期节奏评测。最终结果见根目录`TEST-REPORT.md`。
