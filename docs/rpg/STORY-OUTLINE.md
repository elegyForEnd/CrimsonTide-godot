## 一、全篇讲什么

血月下，王国的晨光被困在失控的月辉回路中。三位守望者原本只为调查一座失联村庄出发，却发现地方灯火正被抽往王城，女王准备把幸存者封入赤晶，以永久停滞换取她所理解的安全。

她们沿途救人、恢复各地设施、查清灾变，最终让六地共同分担能量，在大教堂斩断女王的控制，使真正的黎明重新抵达废墟。

全篇行动链：**救回失联村民 → 查到回路原图 → 测出安全断链方法 → 找到释光出口 → 修复海岸分流和航路 → 联合六地解除王冠控制。**

女王是最终对手；月核失控是同一危机的最后阶段。她曾经救过王国，如今也在主动伤害居民，这两件事同时成立。击败她不等于修复所有损失，结局仍需有人运粮、治伤和重建。

## 三、每一章具体做什么

### 序章：雷霆要塞的南门

**开场问题：静钟村没有回信，但要塞也已缺药缺人。**

1. `P-M01` 今夜仍要生火：在有伤员、铁匠和炊火的营地开场，通过自由交互认识三人和设施。
2. `P-M02` 未送到的信：阿梨带来求助信——修院征走门灯，晨钟却在夜间反复响起。岑烬请小队先探路、救人。
3. `P-M03` 从南门出去：玩家步行出营，学习回程入口。未读求助内容通过出门简报补记，不强制逐个拜访 NPC。

人物基调：绯月急于出发，雪璃默默透支守护，鸦羽先检查退路。三人此时还没有解决血潮的计划。

### 第一章：风铃不再安眠

**章节目标：让静钟村的人能离开，让地方的灯重新亮起来。**

1. `A1-M01` 风铃原野：清开倒车附近的道路，救老人，点亮第一处安全路标。先教玩家保护身边的人，再追击远处的怪物。
2. `A1-M02` 断羽驿路：解开困住药车的污染枝条，带两个孩子回驿站，恢复救援灯架。
3. `A1-M03` 静钟村的门灯：核对征收记录、抵挡血潮脉冲，恢复门灯，分批送居民到安全路标。
4. `A1-M04` 雾桥下的礼拜堂：过雾桥、开圣物箱，雪璃照亮首枚血晶。旧影中的女王曾要求光流向地方，如今方向却被逆转。
5. `A1-M05` 去留之间：允许先撤回补给，再进修院广场。鸦羽开路、绯月追击、雪璃抵挡重击，落实 PV 的三人配合。
6. `A1-M06` 第一座黑钟：深入修院病房、钟绳廊与主钟室，救被限制离开的病人，解除吸能支路，击败赤月葬钟主教，返营报告。

**揭露与转场：**危机来自有人改变了设施用途。血晶记录指向保存维修原图的白垩旧城，小队随护送车前往调查。

**人物变化：**绯月第一次主动停下照看被救者；雪璃承认需要休息；鸦羽开始让同伴参与撤退安排。返营时见到孩子和村民，救援有实际结果。

### 第二章：白垩城的晚祷

**章节目标：让避难庭撑过寒夜，同时查明谁在收紧六地回路。**

1. `A2-M01` 废墟里的市集：进入新营地，救回外街取水队，查明炉渠污染来自王庭导路。
2. `A2-M02` 坠钟广场：停止异常鸣响，为修钟师取回储能石和进入旧城区的路引。
3. `A2-M03` 空着的被告席：调查旧审判庭，关闭刑灯，通过维修记录和证人还原封门命令。
4. `A2-M04` 灰页书库：在两层书库开辟逃生路，救抄录员，取得六路维修原图。抢救人员与保护档案形成有顺序安排的过程。
5. `A2-M05` 炉渠里的冬天：护送维修组，调整排热阀，把地方供热与污染回流分开。
6. `A2-M06` 晚祷之后：击败余烬司祭·晚祷，拆除总控炉芯，保存敕令，回营见证热水和供暖恢复。

**揭露与转场：**敕令证明女王正在主动收紧回路。原图年代久远，需要到月晶高地取得实时相位观测，才能安全改动。

**人物变化：**鸦羽承认自己执行过封门命令，个人线从调查责任开始；绯月必须接受伤害居民的命令确实来自她曾信任的王庭。

### 第三章：星光下的猎场

**章节目标：救下被猎祭体系困住的工人，找到能切断王庭控制又保住地方供能的方法。**

1. `A3-M01` 驿站拒绝的客人：救被拒在驿站外的矿工，打通回营路，取得当地合作。
2. `A3-M02` 骨鹿猎道：解陷阱、救运晶队；通过交涉或战斗处理猎徒，得知猎祭与供晶体系的关系。
3. `A3-M03` 断星矿坑：救工人、修升降机、建立替代线圈，取得相位镜，避免拔走设备后矿坑失去保障。
4. `A3-M04` 天上只有一轮月亮：穿过坠谷登上高塔，完成三组有反馈差异的观测校准，绘出六路相位图。
5. `A3-M05` 誓猎祭场：辨认猎徒身上的外链，解除控制，保留地方月晶供能，为首领战建立安全区。
6. `A3-M06` 猎人的最后一箭：击败荆棘誓约猎王，破坏控制核，回营将猎队集散地改为救援站，开放星桥。

**揭露与转场：**直接强断六路会使地方失去保障。需要将积累的能量安全释放；旧观测资料指出蔷薇行宫保存相关彩窗设计。

**人物变化：**鸦羽在救援中与队友共同撤退；绯月学会等待测量结果，雪璃的提灯获得稳定能量窗口的明确用途。

### 第四章：蔷薇尽处

**章节目标：带活人离开无法结束的旧日幻景，并取回释光结构。**

1. `A4-M01` 墙外的花：协助篱营园丁清除污染土壤、找回工具，进入荒园寻找失踪者。
2. `A4-M02` 会替人哭的刑偶：辨认攻击指令和普通行动，解除控制，保留能帮助居民的人偶。
3. `A4-M03` 嫁衣长廊：用真实物件和前后矛盾的细节辨认镜路。幻景展示三人希望改写的过去，但出口需要她们面对事实。
4. `A4-M04` 花眠庭院：停下循环宴会，拆除镜架，把真实客人与重复播放的影像分开。
5. `A4-M05` 镜墓里的窗框：探索两层镜墓，取得玫瑰窗结构，理解如何把高负载月辉释放到高空。
6. `A4-M06` 让春天结束：击败镜墓纺女·碎影，斩断命线，带幸存者出剧场，回营疏通通往海岸的河渠。

**揭露与转场：**永久保留美好的一刻，也会困住仍然活着的人，与女王的“永夜安眠”形成呼应。释光方案还缺海岸节点分担负载，小队因此前往港口。

**人物变化：**绯月面对五年前的救援失败；雪璃承认守护有范围和限度。她们不能改写过去，但可以改变眼前的行动。

### 第五章：渡过无声的海

**章节目标：先保住海岸居民和返航线，再取得进军王城的条件。**

1. `A5-M01` 还会返航的船：在码头整备，救探潮队，标出安全海岸与可用航路。
2. `A5-M02` 沉舟上的饭桌：找修船工具、航海记录与事故证词，查明七年前海岸导路崩溃的经过。
3. `A5-M03` 潮盐工事：按潮位分时开闸，保护营地支路，掩护维修组，查获封海王令。
4. `A5-M04` 沉钟遗迹：探索两层潮汐地城，利用水位变化通行，恢复逆潮导光槽，建立终局分流节点。
5. `A5-M05` 左边的灯，右边的海：回营核对居民、船只、灯标与补给。玩家可暂缓整备，也可继续挑战总门；决定随时可在准备后重作。
6. `A5-M06` 冥潮守门者：拆除守门者的晶钉控制，击破总门，返营后乘月舟驶向王城。

**揭露与转场：**女王曾压住灾变，后来主动封海并加剧封存。沿途获得的知识与设施已组成可执行方案，小队有能力结束血潮，也为失败或伤员留下返航路。

**人物变化：**绯月的“继续前进”变成三人确认条件后的共同决定；雪璃开始把守灯工作教给居民，鸦羽不再把殿后视为独自牺牲的承诺。

### 第六章：血月尽头

**章节目标：解除六翼和王冠的控制，让此前五章建立的设施共同承担终局。**

1. `A6-M01` 王城残灯：进入最终营地，救朝圣大道上尚未完全晶化的人；开放回访、补给和准备清单。
2. `A6-M02` 圣血外廊：分别停止自动封门、关闭护卫增幅、打开救援通道，救维修工，取得最新总控图。
3. `A6-M03` 失乡庭院：用旧血晶与维修证词说服洛垣，或通过战斗解除其晶化束缚；两条路线都开放王庭通路。
4. `A6-M04` 六翼的根：关闭增幅器，开启高空释光框架，逐一确认六地反馈。原图用于辨认线路，相位镜用于选时，彩窗结构用于释光，海岸节点用于分流。
5. `A6-M05` 王冠之下：绯月先吸引女王，雪璃与鸦羽固定侧道机构。保留 PV 的环形预警、向安全中心闪避和双剑相交；绯月按约定退回，同伴入场。
6. `A6-M06` 血月尽头：三人破坏六翼控制，面对月核失控的最后阶段，在稳定窗口共同释放奥义。赤刃、晨灯、鸦斩汇成玫瑰窗光纹，能量向高空释放，王冠破碎，血潮结束。

**人物回收：**绯月懂得等待队友；雪璃守住自己能承担的空间；鸦羽相信同伴会一起回来。终局奥义由一路建立的知识、设施和信任支撑。

**女王的选择：**她认为封存可以终结饥饿与失去，三人则要求把生活的决定权还给居民。能否救下破冠后的女王取决于事先的救援准备；活下来也必须承担责任。

### 终章：把眼睛交给清晨

`E-M01` 第一束光：三人站在仍然破损的城垛上迎来晨光，保留 PV 最后的共同画面。随后把控制权交回玩家，走下城垛、回营报平安，与医护和联络人完成最后一轮交互。

基础结局“残城的黎明”必定结束血潮；公共准备充分时追加“归途的灯”，呈现更多居民和航路；完成个人线与救援证据准备，并选择救她时追加“未完的守望”，女王作为失去王权的幸存者留下。两个追加收束可以同时出现，具体条件沿用现有任务索引。

通关后可回访六地，看见灯路、炉渠、矿工、园地与港口的变化，接取重建委托。废墟仍需重建，黎明本身就是本篇已经兑现的成果。

## 四、任务系统如何服务这份剧情

现有内容已具备稳定任务 ID 和六幕基础推进。后续优先把文案中的行动做成能被玩家操作和观察到的过程。

1. **按行为完成目标。**救援验证人员到安全点；修复验证设施状态；调查验证证据取得；分支记录采用的解决方式。减少用同一类顺序交互包办全部任务。
2. **每章形成不同节奏。**第一章重救援，第二章重调查与供热，第三章重观测，第四章重辨认，第五章重潮汐与交通，第六章综合回收。首领是地方危机的控制者，击败后还要确认危机解除。
3. **让日志说明行动理由。**每个主线写清“为什么做、当前做什么、在哪里、办成后改变什么”；完成后更新结果和下一条线索。
4. **保存救援与设施结果。**使用稳定事件和对象 ID 记录已救居民、灯路、机关、证词及分支，支持回访、加载和提前探索，避免要求重复办理。
5. **每章至少一个可见结果。**村民回营、热水恢复、矿工下山、人偶修园、航标亮起、王城伤员获救。支线扩大这些成果，基础主线始终具备通关所需条件。
6. **选择允许整备和补做。**撤离回营后可续接；关键证据不占普通背包、不被出售；进入终局前明确列出缺少的准备，并保存战前记录。

建议先完成第一章的“倒车救援 → 药车与孩子 → 门灯疏散 → 血晶调查 → 去留选择 → 修院解除吸能”完整闭环，验证任务事件、日志和营地变化，再按各章需要扩展机制。
