# 第一批五把武器：实际形状与连续时序修订

本页记录第一批：607 鸣电军刀、608 断誓直剑、612 破晓双手剑、614 裂地重剑、617 雷骸重剑。用户随后已明确要求继续完成其余所有武器，不再逐批等待验收。

人物使用原有精灵图与图集配置；新生成人物草稿已取消、设为忽略，未接入游戏。原 `hero-0.png`、`character_frames.gd`、`weapon_atlas_frames.gd` 与原角色图集 manifest 均未改动。

## 主形与阶段

每把的普攻、重击、战技分别绘制实际形状，见 `assets/combat/weapon-batch-01/<编号>/shapes.json`。617 直接以用户提供的弧形拖尾细节为依据。材质保留已画出的弧面、纸带或细电轴，不再把所有主形强行套在同一个直带上。

阶段图共用虚拟画布、手部锚点与接触锚点，不独立居中或缩放。人物不变，特效只调整表现。多阶段源图原始像素保留，`prepare_weapon_shapes.py` 检测透明间隔、记录采样范围并核验原图 SHA-256。612 重击与战技使用单独的完整峰值源图，避免有交叠的草稿被裁断；其展开、断尾与消散连续计算，不硬凑多张图片。

`weapon_actual_shape.gdshader` 保留同一条峰值轮廓和亮边，阶段信息调制密度与消散；连续展开遮罩沿弧面/突刺运动，防止简单叠帧产生第二条亮边。

## 时序与交接

前摇后段提前展开斩击，释放时继承阶段状态，命中不再强行跳过准备好的视觉时间轴。按用户新增要求，战技现在采用三段真实攻击与位移，最后一段扩大覆盖；总基础伤害按 20% / 25% / 55% 分配，消耗与冷却只结算一次，按次触发的构筑效果共享同一上下文。重击保留原单次蓄力招式。

尺寸按两次缩小反馈收敛：战技收尾为最初新版距离的 76.5%，前两段为 95%；位移和腾空节奏保留。普攻重新生成五个独立主形，战技新增五个收尾主形，原人物精灵不变。破晓与雷骸的跳跃由实际高度轨迹驱动；位移经过地图碰撞，闪避、换武器、离开战斗会取消剩余段数。

主形与命中共享方向和落点；独立命中图不重复包含主斩击。608 的纸带由主形承担，接触补独立纸屑；614 战技的土脊主形不再重复叠完整土脊爆发。612/617 接触图分离直立碎岩与贴地部分，在同一接触线交接。飞散碎片按最长边定尺寸，避免竖长源图变成巨大的倒插石柱；烟雾使用稀疏独立漂移粒子。
