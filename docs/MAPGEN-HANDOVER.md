## 1. 一句话目标

把现在的**固定手绘 9600×7200 地图**，换成**10 倍面积、45 分钟、35–42 个大区 + 20% 碎块**的随机大陆：

- 每局一张新图，但模块可学习、组合不可预测；
- 难度不按“离中心多近”排，而由**折叠的馅料场 + 折层深度**决定；
- 玩家小地图看到的是**生成后的地势**，不是抽象模板；迷雾只亮走过的部分；
- 先解决生成与流式，再放大到 10×；**不许先改大再补流式**。

## 3. 术语（以后统一用这套）

| 词 | 指什么 | 不是什么 |
|---|---|---|
| **地脉** | 一局地图的抽象骨架：区域种子、危险范围、水域意图、Boss 核心、出口 | 不是地形、不是玩家地图 |
| **地势** | 真实高度/河湖/崖/路/建筑地基；玩家小地图的数据源 | 不是生成模板 |
| **图版** | 可复用的手工模块：18 个现有据点、竞技场、陷阱场、王城、渡口 | 不是随机噪声 |
| **地物** | 树、石、家具、雾、血迹等摆件 | 不参与规则 |
| **织脉** | 生成一张地脉的动作 | 不是“画地形” |

> 上一版原型里把抽象区域图标成“玩家看到的地表”是**错的**；那张只是地脉模板。
> 玩家看到的是 **地势图**（山川河流），不是区域格子。

## 4. 体验模式：读图—押路—收潮

- **一张图用三天**：第一天认路，第二天开高难，第三天收潮；不每天重生成。
- **五类区域**：新手（绿）/ 探索（黄）/ 打架（橙）/ 陷阱（紫）/ 高难（黑）。
- **风险不是环，是折层**：馅料场像花卷一样折叠，高危核心散落；同一难度带上可能长探索区，也可能长打架区。
- **三种玩法都有路**：
  - 快线：出生 → 2–3 个过渡区 → Boss，8–12 分钟；
  - 富线：穿打架区/陷阱区，装备与材料最多；
  - 安全线：外圈探索、搜刮、撤离。
- **收潮**：撤离点在外圈，越深越肥、回程越长；Boss 场有“深井电梯”候选（只带一半战利品，P5 再定）。
- **反“中心最难”的五条硬规则**：
  1. `danger` 不加径向项（<3% 且不可读也不行，干脆不加）；
  2. 15–20 个馅料核心散落，有的靠海；
  3. 故意放 1–2 个“深处安全窝”和 1–2 个“靠海露馅的高危点”；
  4. Boss/潮心从高危核心里随机选，不是几何中心；
  5. UI 不给全局热图，只给局部提示（裂缝、气味、鸟群、血迹、情报）。

## 5. 生成规范 v0.1

### 5.1 总管线

```
织脉（地脉模板）
  → 塑形（地势：高度/河湖/崖/路/地基）
  → 盖图版（建筑/据点/神龛/出口）
  → 点景（地物/雾/血迹）
  → 验证（连通/配额/可达）
  → 分块（chunk/index/hash）
```

### 5.2 Pass 表

| Pass | 名称 | 输入 | 输出 | 关键规则 |
|---|---|---|---|---|
| P0 | 种子/契约 | `seed`、`layout_version`、人数、难度 | 各 pass 独立 `rng` | 每 pass 单独 salt；改一个 pass 不重排全图 |
| P1 | 陆块 | 噪声 | `land` 掩码、海岸 | 不规则海岸；保留最大陆块；无必须横穿的河 |
| P2 | 高度/折层 | 噪声 + 折场 | `height`、`fold` | 折脊/折谷/盆地；加一条斜向山脊；不按中心 |
| P3 | 水域 | `height`、盆地 | `water`、`rivers`、`lakes`、`ferry` | 见 §5.4 |
| P4 | 危险场 | 折场 + 核心 + 噪声 | `danger` | `danger = 0.45*fold + 0.35*ridge + 0.20*noise`，**无径向项** |
| P5 | 撒米 | `land`、`danger`、`fold` | 35–42 大区 + 8–10 碎块 | 蓝噪声 + 折痕密度加权；**不做环带采样** |
| P6 | 口→回 | 大区掩码 | 深度 0–3 的子区 | 每个区向内腐蚀一圈，内部再撒 2–4 个子种子；父环保留 |
| P7 | 类型/配额 | `danger`、`depth`、`expose` | 五类 + 隐藏/露出 | 保底 1 新手、≥1 高难、≥3 打架、≥3 陷阱；其余探索 |
| P8 | 道路/据点 | 区域种子、`height`、`water` | 道路、POI | A* 沿低危险折谷；MST + 少量环路；每大区 2–3 个图版 |
| P9 | 特殊结构 | 区域/水域 | 5 出口（封 2）、3 神龛、Boss、王城、渡船 | 出口绕外围分散；Boss 在高危核心；王城全图唯一 |
| P10 | 验证 | 全部 | pass/fail + 失败原因 | 失败 `seed+1` 重试 ≤8 次；仍失败回退 legacy |
| P11 | 分块/输出 | 地势 | chunk、碰撞索引、小地图、`layout_hash` | 分块确定性生成；动态状态走快照 |

### 5.3 区域尺寸 / 深度 / 配额

- **大区 35–42 个**：
  - 大区 6–8 个（25–40M px²，必须含 2–3 个图版/卫星）；
  - 中区 20–24 个（10–20M px²）；
  - 小大区 8–12 个（4–10M px²）。
- **碎块 8–10 个**（2–8M px²），用菱形标记；可贴在大区边缘，也可以是独立微型高危窝。
- 总数目标 **45–52**；少于 45 补碎块，超过 52 合并最小碎块。
- 任何区域面积 > 35M 或 > 2.5× 中位数 → 强制切 2–4 块。
- 深度分布目标：**d0 55% / d1 28% / d2 13% / d3 4%**。
- 馅料 +20%：d1 14–18 个、d2 6–8 个、d3 1–2 个；露出的裂缝 30–35%。
- 类型配额：新手 1、高难 1–3、打架 ≥3、陷阱 ≥3、其余探索；碎块偏向陷阱/打架/高难。
- 图版落点总数 **80–120**；箱子 **20–24**；神龛 **3**；地图守卫 **3**（5 选 3）；Boss **1**；王城 **0–1**。

### 5.4 水域（按“小一点”修正）

- **数量**：1–3 条河 + 2–4 条短溪 + 2–5 个湖；至少 1 个可通航水体。
- **占比目标**：陆地面积的 **6–10%**（原型约 13%，偏多；正式按 6–10% 调）。
- **河**：
  - 从高处取源点，沿最陡下降 + 蜿蜒噪声走；遇海/湖停止；
  - 不必横穿地图；可长可短；短于阈值算“溪”；
  - 多条河可汇合；按流量加宽；河道下切，两岸形成浅滩/桥位。
- **湖**：
  - 找低洼盆地，按水位填充；或放 2–5 个盆地再灌水；
  - 大湖 1200–2200 半径，小湖 400–900；
  - 可有 Highland 小湖；至少 1 个湖与河/渡船连通。
- **渡船**：
  - 选最大可通航水体（湖或宽河）；3 个码头；
  - 固定班次，到站会引怪；是“省时间但冒险”的选择；
  - 不做滑索/坐骑/传送门。
- **规则**：深水阻挡、浅水减速；桥/渡船过河；水路可作为区域边界/隘口。

### 5.5 道路 / 特殊结构

- 道路用 A*：`cost = 1 + 9*water + 5*slope + 0.8*danger`；沿低危险折谷走，不画放射状主干。
- MST 连所有大区 + 6 条环路；碎块用一条支路连最近大区。
- 出口：5 个沿外围分散；随机封 2 个（地图上显示“血潮封死”）；开放 3 个至少覆盖 2 个象限。
- 神龛：3 个，分布在探索/打架/高难各至少 1 个。
- Boss：从 top danger 核心里随机选 1 个；竞技场半径 800 净空；至少 2 条入口。
- 王城：全图唯一，独立 interior 图版；可选，不是必经。
- 渡船：3 个码头；只画码头和船，不画跨陆直线（原型踩过这个坑）。

### 5.6 验证清单

- 出生点 → 3 个开放撤离点，存在**不经过高难区**的路线。
- 3 个神龛、Boss 场、95% 图版可达；没有图版卡在墙里/水里。
- Boss 场中心 800 半径内无障碍；至少 2 条入口。
- 新手区不直连高难区。
- 至少 1 条长河 + 2 条短溪 + 2 个湖；可通航水体存在。
- 人数缩放：4 人局的箱子/掉落预算不能只够 2 人。
- 失败重试 ≤8 次；仍失败回退 legacy 固定图，绝不把坏图交给玩家。

### 5.7 种子 / 确定性 / 联机

- 每个 pass 用 `hash(seed, pass_id, salt)` 派生独立 RNG；改一个 pass 不重排全图。
- `layout_version` 变更即作废旧种子；握手带 `map_seed + layout_version + layout_hash`。
- 静态地势由种子确定性生成；客户端不需要同步墙/地形。
- 动态状态（箱子、钟、桥塌、渡船位置）走快照。
- 房主权威；客户端只读。

## 6. 迷雾规范

- **只亮身边固定半径**：`REVEAL_RADIUS = 900.0`（按 1440×900 标准镜头标定，约 1.1× 半对角线）。
- **不读 viewport / 预渲染气泡**：调大窗口、调大视距、换大屏都不会多亮。
- 预渲染 3×3 块只用于 LOD/流式；屏幕真渲染只用于画质；**都不参与点亮计算**。
- 探索位图：每块 1 bit / 16 px；沿移动路径画胶囊；285 块约 350 KB。
- **区域名**：
  - 区域探索度按 12×12 **可行走格**算；≥80% 才记名；
  - 名字显示在**已探索点亮的对应区域内**（用户 2026-10-19 确认：中心在哪已不重要）；
  - 不画区域轮廓；不在地图上给未探索区域任何形状。
- **情报点**：
  - 只在区域内随机位置给一个区域名；
  - 不给轮廓、不给地图方位；最多一句模糊传闻（“北边水声很大”）。
- 小地图：地势草图 + 迷雾；没有区域边界；名字只在已知后出现。
- 联机：队伍共享探索位图；谁走过都算；Boss 场强制点亮给参战者。

## 7. 流式加载与联机

### 7.1 数字

- 10× 图 ≈ **30,400×22,800**；块 **1600×1600** → **19×15 = 285 块**。
- 视觉气泡：自己相机周围 **2–3 块**（3200–4800 px）；超出 4 块卸载；滞回。
- 模拟气泡：主机只在玩家周围 **1.5 个屏幕**内模拟怪；气泡外冻结/回收；Boss 强制气泡。
- 汇合：两人距离 <2 块合并气泡；分开各自独立；每个客户端只收自己兴趣集内的实体快照。
- 过场：渡船/滑索跨未加载区先预载目标块，0.3–0.5 秒淡入，不黑屏。
- 版本：`map_seed + layout_version + layout_hash`；不一致拒绝加入。

### 7.2 性能红线

- 每帧最多建 1–2 个块的网格；超预算排队。
- `ruins.blocked()` 现在是全 features 多边形测试；10× 必须换**块内空间索引**。
- 小地图不画整图 `chart`；只画已发现区域 + POI + 迷雾。
- 目标：流式 <4 ms/帧，模拟 <8 ms/帧；达不到就降视距/刷新率。
- 联机兴趣管理：只发动态实体，不发静态地形。

## 8. 地势 / Z 轴

- **图版 schema 从第一天就带**：
  ```gdscript
  {
      "id": "old_chapel",
      "size": Vector2(500, 400),
      "foundation": Rect2(...),         # 盖章前压平地基
      "levels": [
          {"z": 0.0, "floor_polygon": ...},
          {"z": 3.2, "floor_polygon": ...}
      ],
      "links": [
          {"kind": "ramp", "from": {"level": 0, "at": ...}, "to": {"level": 1, "at": ...}, "width": 90},
          {"kind": "ladder", "from": ..., "to": ..., "width": 40}
      ],
      "walls": [...], "props": [...],
      "loot_profile": "tier2_indoor", "enemy_budget": 2,
      "tags": ["explore", "indoor", "shrine"]
  }
  ```
- 地势 API：`height_at(p)` / `level_at(p)` / `can_traverse(from,to)`。
- P1 先全部 `level=0` 平地；P2 起伏；P3 二层楼/爬梯。
- 不做跳跃键：坡道自动走、楼梯自动上、梯子按交互键“攀爬”。
- Boss 场强制压平；建筑 `foundation` 压平；坡度过大的地方不盖多层图版。
