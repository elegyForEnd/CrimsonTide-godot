# 《赤月遗书》女王新版 · 全流程与演出衔接

2026-10-16。配套 [当前故事](SCARLET-QUEEN-REWRITE.md)、[同源任务索引](SCARLET-CONTENT-INDEX.md)、[导演台逐镜提示词](SCARLET-H3-DIRECTOR-PROMPTS.md)。旧求死信剧情退出当前版本。

## 总流程

女王核撤运、写短召信 → 客舍读信，绯月担心北岸 → 弩手袭击，救信使 → 查护送路线与封存令 → 取药、读医疗记录、救囚车 → 审判官战，收到拨药也催归的第二封信 → 查剑与救医师 → 法官战保原件 → 维恩路线背叛、分支救援与旧骑士战 → 鸦羽带剑独谈失败 → 行宫救人、查十年前继位备选与剑柄 → 瑟芮战、选择先回家 → 修船、吃果酱 → 红潮救七人、查封航 → 测潮痕、实测泄压依据、撤高坡居民 → 公布破契与撤船计划 → 提督战放民船 → 自主驶往王城 → 开水门退路、侧廊、泄压与稳流 → 女王审名单和图纸，仍拒绝破源、要求移交 → 三阶段战与三人终结 → 玩家决定救女王或离开 → 外墙黎明 → 自己走回水门 → 对应后日谈与船上回信。

## 任务如何证明人物

绯月的善良体现在强制推进主线的救援、药箱、担架与等最后一船，不以“拒绝救人才能成熟”作为路线。玩家可以拒绝女王，同时承担自己选择的工作。支线不累计善良值，不锁最终救援选项。

女王通过具体命令出场：例外保护、隔离和供药并行、优先护送、按北岸容量排船、准许移交。不让她每章出一次镜头讲解幕后真相。小队与玩家知道的事仍分开。

## 结局与 E01

胜利落盘后无实时伤害，选项无读秒。救援仍可用既有绳锚与回程点，CIN-17A 后医护与看守接手；告别线 CIN-17B 三人撤出，女王留在塌落侧台。善良不作为强制选择救她的资格考试。

两线均在外墙接收后，玩家主动到观景点才 CIN-18。片里只有雪璃左、绯月中、鸦羽右，断柄不恢复，城市不复原。淡回后仍需自己走回旧水门，E01 才收束。

救援后日谈 CG-16A：女王先问最后两船，要求命令按原件留存；绯月不删问询，不求准令。告别后日谈 CG-16B：断柄留水门，信带走。共同 CG-17：绯月翻召回信，写给医棚与村医，由自己决定下一步。

## ADV、存档与素材约束

表情按每页 `expression/pose` 切换；女王常态保持 neutral，受战术挫折或强迫时才 angry，不用频繁惊慌或哭泣替代威严。Boss 战术台词不中断操作。
