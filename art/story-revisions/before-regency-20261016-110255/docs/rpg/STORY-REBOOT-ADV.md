# 《血潮守望》全新 ADV 剧情案：《赤月遗书》

2026-10-15 · 全新故事提案，替代前三版大纲

配套制作文档：[全游戏流程与剧情触发表](STORY-FLOW-ADV.md)／[CG与过场动画制作表](STORY-CG-PRODUCTION.md)。完整播放时点、分支、操作衔接与结局回营流程以配套文档为准。

## 创作边界

沿用用户 PV 中的绯月、雪璃、鸦羽、血潮女王、哥特废墟、血月、礼拜堂血晶、去留抉择、三人协同与废墟黎明。**晨钟、晨火、六地回路、弃守名单、撤离签名、露诺全部退出本案。**雪璃的提灯是照明、治疗与防护法器，没有“原初晨火”设定。

本案新增的“女王是绯月姐姐”、王冠规则、人物前史及新 NPC 都是本次原创提案，并非 PV 原有设定。女王与绯月始终是两个独立人物，王冠及恰好六片彩窗刃翼只归女王。本案的剧情事件在 scripts/scarlet 与 resources/scarlet 实现；地图、渲染、角色动画、战斗特效与行囊界面直接复用原项目，新事件层只负责剧情和新增玩法。旧故事正文保留作历史参考。实现范围见[SCARLET-IMPLEMENTATION.md](SCARLET-IMPLEMENTATION.md)。

采用带探索与动作战斗的 ADV 结构：以绯月为主要叙事视角，少量明确标注的鸦羽视角；每章六项主线、一个章节大 Boss。任务随事件改变目标，章节结尾有确实改变局面的转折。角色演出、调查、行动、战斗各有职责，不把对白当战斗之间的说明书。

## 一、故事的中心

**离别十年，绯月终于收到姐姐的信。信里要求她带着小时候获赠的剑，进入王城，亲手杀死已经成为血潮女王的姐姐。**

姐姐说，自己正被王冠吞噬，死亡是结束血潮的唯一办法。

绯月相信了半封。她想去，但想带姐姐活着回来。雪璃愿意陪她查证，鸦羽则是受雇保护她进城的前王庭执刑人。三人都不知道：那把绯月舍不得换掉的旧剑，才是信里最重要的东西。

进入王城的路被封锁。追捕者一面杀死知情人，一面坚持不能伤害绯月。帮助她们的旧骑士在最接近王城时出卖小队；鸦羽随后带剑独自离开；绯月最终发现，姐姐确实在求救，却准备让她代替自己承受王冠。

最后的冲突是姐妹之间的一次拒绝：绯月仍然爱姐姐，也有能力理解她为何想逃，但不再把服从姐姐当成爱她的唯一方式。

## 二、只建立三条超自然规则

**王冠。**旧王室利用地下封存的“赤月之骸”获得力量，王冠是控制它的契约器。佩戴者能压制也能放出血潮，身体却会逐渐晶化。女王十年前接位，如今已接近承受极限。她保持清醒，近来的封锁、谋杀和强迫继位都是她的选择，不由一个突然登场的幕后人格代替负责。

**血契剑。**绯月的赤晶剑与女王王冠取自同一块母晶，能切入王冠保护的身体。女王登位时以亲属之血留下了唯一继位契印，契印藏在妹妹的剑柄里。若用它刺穿在位者心脏，契约会经剑转给持剑者；两人不交换身体、记忆或外貌。妹妹不是克隆体，也没有缺失关键记忆。

**解除契约。**单纯杀女王不能消灭赤月之骸。真正解除需在王座仪式打开母晶时，破坏王冠、继位契印与地下母晶三个实体。此前没有可从外部随意攻击的入口；女王为继位主动开启仪式，才制造最终机会。三人分别用剑切冠、提灯撑住晶潮、长刀切开王座束缚，完成同一场战斗。不会走遍六地寻找六枚同款钥匙。

血契剑也是小队手上唯一能切开王冠与母晶的武器。继位契印与剑柄母晶同体，粗暴毁印会使整把剑碎裂；提前毁剑能拒绝继位，却无法终止仍在扩大的血潮，因此她们要保留它至最后一次攻击，再毁掉契印。拆柄检查只暴露结构，不会让契约自动消失。女王失去王冠后仍可能存活，但晶化造成的伤势需要治疗，不随血潮消失而痊愈。

血晶可以储存少量影像，记录必须有实物来源、时间和拍摄范围；不能读心、预言、复活或无限伪造任何人的过去。礼拜堂记录只拍到一次医疗处置，不负责替全篇解谜。

## 三、三位主角的关系怎样变化

**绯月：把重逢看得比真相重要。**她知道姐姐是女王，知道十年前姐姐主动留下自己，仍珍藏那把礼物。她不是什么都不知道的白纸：她记得姐姐会替她遮雨、讨厌苦药，也记得离别前姐姐没有回头。收到信后，她愿意怀疑所有人的解释，却迟迟不肯怀疑“姐姐希望我好”。到第四章，她必须主动调查自己最珍惜的剑。

**雪璃：敢于说出让朋友不高兴的话。**她与绯月在边境相识，了解她嘴硬的一面。开场她就指出信有问题，后来承担检查伤口、保护证物和劝阻冲动的行动职责。她不会永远温柔地同意。绯月指责她不了解姐姐时，她会生气；争吵之后是否继续同行，需要具体道歉和选择，不靠一句万能安慰恢复关系。

**鸦羽：习惯把真实意图藏在行动里。**她曾为王庭执刑，因为拒绝处决一名医师而脱离王庭，身体留下会被王庭药物缓解的晶化旧伤。她接下护送工作既为钱，也为接近王城毁掉契约研究。她中途夺剑，是想拿剑逼女王放弃妹妹；她的判断失败，因为独自交易重演了王庭替人决定的方式。后半程必须把自己知道的事和退路说给同伴，再一起行动。

小队关系不靠持续互怼建立。每章有一段可停留的日常：擦剑、处理伤口、分食不够甜的果酱、争一张干燥床铺、谈结束后去哪里。后来的背叛和离队，才会伤到具体的相处。

## 四、ADV 开场实写：《她寄来一封遗书》

建议演出 5—7 分钟，可手动推进、回看、自动播放与跳过。先给一段完整事件，再进入营地操作。以下为开场台词样稿，不是仅供概括的剧情简介。

### 场景 01：血月下的王座

【背景】破损大教堂。六片彩窗刃翼在王座后缓缓收拢。女王摘下一只手套，手指侧面已有细小晶纹。

【音效】笔尖划纸。窗外风声。

**女王：**绯月。

她停笔，将这个名字划去，换到一张新纸。

**女王：**如果信能送到，你应该已经长大了。

【画面】镜头只展示第二段：“带上我送你的剑。到王城来。亲手杀死我。”前文正常写在纸上，稍后取得实物可读，不用镜头刻意遮住关键答案。

侍从在门外问是否需要再添一盏灯。

**女王：**不用。她看得清。

她将信封好，蜡印边缘缺了一角。镜头切黑，出现篇章名，不先讲解王国历史。

### 场景 02：雷霆要塞，清晨之前

【背景】营地客舍。桌上摊着护具，窗缝漏雨。雪璃用一条旧布垫住绯月的剑，免得滴水落到刃上。

**雪璃：**你昨天说要换剑鞘。

**绯月：**今天换。

**雪璃：**上次的今天，是半个月前。

门外传来脚步。旅馆主人带来一个浑身湿透的信使。信使拒绝坐下，只问她是不是绯月。绯月看见蜡印，先叫雪璃把窗关上。

信使确认剑柄上的红晶，递信。

**信使：**她说，你认得这个。

**绯月：**她还活着？

**信使：**活着。但我劝你——

他看见窗上的影子，猛地将绯月推开。

【音效】窗碎。箭钉进桌面，第二箭击中信使。

### 场景 03：被追杀的送信人

雪璃压住伤口，绯月拔剑挡在窗前。旅馆主人逃到门外呼救。鸦羽从走廊冲入，切断追来的弩索，把靠窗柜子推倒遮住两人。

**鸦羽：**带他走。窗外有第二组。

**绯月：**你是谁？

**鸦羽：**你姐姐雇来送你进城的人。

**雪璃：**那外面也是她雇的？

鸦羽没否认。她从被切下的弩索取下一枚王庭扣件，放在桌上。

**鸦羽：**现在出去问，他们只会再射一次。

信使抓住绯月的袖子，指向剑。

**信使：**她要你带它去。不是为了让你救她。

他示意雪璃翻开自己的内袋，里面有一张偷来的追缉令。雪璃将纸放到灯下：

“送信人抵达后灭口。护送绯月入城，不得损伤。同行者不在保护之列。”

纸上是同样缺角的蜡印。

**绯月：**这是假的。

**雪璃：**我还没说是谁写的。

绯月握紧信封，没再说话。

### 场景 04：她们要带谁出门

雪璃说明信使尚有呼吸，必须立即转移到要塞内侧医棚。鸦羽说追杀者正在包围客舍，再拖会堵死门。

【首次选项】“我背他，你开路。”／“先告诉我，你知道多少。”

第一项立即安排分工；第二项让鸦羽给出“信使偷了密令，我只知道任务改过一次”的信息，再由雪璃提醒先救人。两项均救援，不设置无预告的致死选择。鸦羽会记得玩家先问信息还是先交托行动。

**绯月：**你收的是送我进城的钱？

**鸦羽：**是。

**绯月：**那就先保证，我们三个都出得了这扇门。

【转场】立绘淡出，进入营地客舍外的可操作场景。目标出现：“护送伤者到医棚，甩开追兵。”

开场的抓手是两封矛盾命令、一次未结束的追杀和一段不可靠的雇佣关系。女王的目的还没揭晓，但玩家已经知道要保护谁、眼前能信谁到什么程度、下一步该做什么。

## 六、第一章《姐姐不会寄第二封信》

**情感起点：**绯月相信杀信使的命令来自冒用印戒的人。雪璃不认同，但答应先找证据；鸦羽只肯确认追兵属于王庭，不替女王判断动机。

**章节事件：**离开要塞后，小队发现边境教会正在搜缴王室旧物。信使曾在遗灯礼拜堂更换马匹，那里藏着女王近年的医疗血晶。绯月想证明姐姐受制于人，读出的记录却显示女王亲自批准了秘密处置。

| 任务 | 地点与剧情驱动 | 玩家行动、完成判定与结果 |
|---|---|---|
| `R-1-01` 不许回头的路 | 风铃原野。王庭追兵在搜查出营道路，直走会把他们引回医棚 | 利用假脚印、废车与岔道误导追踪，清掉拦路小队后从另一端过河；确认追踪标记消失，营地暂时安全 |
| `R-1-02` 信使换过的马 | 断羽驿路。驿夫声称从没见过信使，马厩里却有他相同的鞍扣 | 检查鞍具、马蹄泥和账上空栏，拿证物追问而非重复穷举台词；驿夫交代礼拜堂接头及审判官正在搜村 |

| `R-1-06` 缺角的蜡印 | 白钟修院，修院保留现有地名但不引入钟相关设定。审判官承认追缉令是真的 | 击败审判官、保住传令匣；匣中有针对绯月的完整护送命令。章末女王再次来信，直接叫出雪璃与鸦羽姓名，承认她知道同行者 |

**章节 Boss：血烙审判官·赫缄。**女王的边境清道者，主动灭口并借“保护殿下”限制妹妹。他从驿路起通过封条、通缉和搜村参与剧情。机制为锁链划定禁区、烙印追击、弩台交叉火力；玩家拆弩台、以柱体挡链，再攻击甲胄接缝。第二阶段他放弃活捉其他人，只集中抓绯月，小队必须互相解束。人格是残酷而自负的执法者，不给他临终洗白。

**章末演出：**女王信里说：“你不该把她们带上。你总是舍不得丢下捡来的东西。”绯月将纸反扣，雪璃已经看完。两人第一次真正在姐姐的问题上争吵。目的地变为白垩城——那里有制作赤晶武器的旧工匠，能解释信使为何指着剑。

## 七、第二章《替她说谎的人》

**情感起点：**绯月想知道剑的秘密，又不愿让人拆开姐姐留下的剑柄。雪璃因“捡来的东西”受伤，绯月需要亲口说那不是自己的意思，而不是假装信没发生。

**章节事件：**绯月幼时认识的骑士维恩在白垩城找到她。他曾替姐妹送信，比陌生的鸦羽更容易得到信任。他提供住处、证人和进城办法，还承诺亲自带三人走过高地。事实调查却显示：女王成为现在的样子始于一次有计划的王冠手术，继任者从一开始就被预留。

|---|---|---|
| `R-2-01` 叫我旧名字的人 | 白垩外街。维恩叫出绯月幼时小名，在追兵出现时帮她解围 | 与他协作摆脱街巡、安置受伤路人；取得真实可用的庇护和工匠地址，建立他值得信任的行动依据 |
| `R-2-02` 姐姐送我的东西 | 坠钟广场工匠铺。工匠认出剑，却先要求找回被扣的制剑底稿 | 潜入封店查封处、对照模具与剑纹；工匠只做外部检验，发现剑柄有不能粗拆的血契封印；绯月暂时拒绝拆柄，留下待验证问题 |
| `R-2-03` 还活着的证人 | 旧审判庭地下。被女王清退的医师尚未处决 | 用监牢值班表和钥匙分配救出医师，短护送离开；医师说明“杀死佩冠者”和“结束契约”不是一回事，但手术原图已被封存 |
| `R-2-04` 剑上没有写给你的名字 | 灰页书库。手术原图被拆成正文与解剖页，页码与装订可复核 | 找固定档位、按图叠合，认出绯月剑的母晶编号对应“继位器”；雪璃提出暂存武器，绯月拒绝并指责她想阻止自己见姐姐 |
| `R-2-05` 谁都别替我决定 | 地下炉渠作为出城暗道。医师必须离城，王庭法官封锁出口 | 队伍先分工送医师到安全支路、停止蒸汽外泄、开排水门；绯月向雪璃道歉，同意让她持有图纸，三人进入法官所在礼堂 |
| `R-2-06` 判决之前 | 焚书礼堂。法官准备处置证人并毁图 | 击败法官，救下被转移的工匠学徒、保住手术书；医师用实物演示契印可转移，尚不能确认持剑继位条件。维恩安排次日越山 |

**章节 Boss：王庭裁决官·白面法官。**他用三具宣判甲偶维持距离，把战场切成互相封闭的庭区；玩家关闭机关让同伴重新汇合，迫使其本人离开安全席。第二阶段他亲持刑剑近战。其目的很具体：销毁能证明王冠需要不断更换佩戴者的证据；他的“依法办事”只用一小段对白揭穿，不再开展旧案名单审判。

**章末演出：**夜里维恩替绯月系好护手，像小时候一样说“你姐姐一直在等你”。玩家随后看到短短一幕：他在灯下写出路线，将“其余二人”标为可处置。这次不向玩家隐瞒危险，让玩家带着比主角多知道一点的信息进入第三章。

## 八、第三章《替你挡刀的人，也会把你交出去》

**情感起点：**三人关系刚有所修复，维恩的关照使绯月感到久违的家庭安全。玩家已知他有问题，悬念是证据何时足够、她会怎样面对，而不是重复表演一个毫无线索的突袭。

| 任务 | 地点与剧情驱动 | 玩家行动、完成判定与结果 |
|---|---|---|
| `R-3-01` 一条太顺利的山路 | 月晶坡地。维恩选择的路没有巡兵，却有刚铺好的临时路标 | 勘查路标与伏击高点，可提前布退路或继续跟随；提前发现会改变伏击起手，不会因剧情强行让玩家忘掉发现 |
| `R-3-02` 为谁设下的陷阱 | 骨鹿猎道。维恩借口引开追兵，山门随即落下，捕猎索只避开绯月 | 在伏击中切索、救同伴、启动预布退路。无准备时雪璃被带进矿坑；有准备时她主动护送伤者退入坑道，接下来的营救变为接应，不强制抓走成功逃脱的人 |
| `R-3-03` 别替我数剩下多少人 | 断星矿坑。队伍需救出或接回雪璃及同行伤者 | 重启升降架、关闭排气毒雾、短战解决守卫，找齐被隔开的人员后共同上井；鸦羽晶化旧伤发作，雪璃在被救后反过来救她 |
| `R-3-04` 他没有走远 | 流星坠谷。维恩试图把绯月单独引到约定交接点 | 对照弩箭来源和临时路标，取得他留给王庭的信；是否已有怀疑只改变质问顺序。他承认从接到信起就知道女王要她继位 |
| `R-3-05` 你还肯叫我一声叔叔吗 | 观星高塔改作王庭山地信站。维恩要发讯号召来押送队 | 玩家分两路登塔，破信标、开侧梯，撤走被扣旅人；绯月亲自拒绝随行，维恩不再伪装保护，退到祭场要用武力带走她 |
| `R-3-06` 旧骑士最后的工作 | 誓猎祭场。维恩封住唯一可供担架通过的出口 | 击败维恩，保持担架撤离路畅通；他活着被当地守备拘押，暴露女王许诺恢复其爵位，他把效忠置于妹妹意愿之上。可怜悔恨不能抹掉收买 |

**章节 Boss：王庭旧骑士·维恩，封号“誓猎骑士”。**前两章真正帮过小队，所以背叛伤害信任。他用绯月童年练过的剑路诱导追击，再以重盾反制；第二阶段烧断侧桥，鸦羽与雪璃打开先前布好的援护通道。提前勘查让玩家开局多一条通路，但未勘查仍可正面解决。战后允许质问或保持沉默，不能以一句话决定他立刻自杀。

**章末悬崖：**绯月睡前同意让工匠拆柄，准备次日彻查。半夜醒来，剑和鸦羽都不在。雪璃在桌上找到一行短字：“我知道该拿它和谁谈。别跟来。”刚经历一次被交出去的绯月，认为自己再次相信错了人。

下一章必须切换鸦羽视角，给玩家看到她在做什么；不把所有人长时间蒙在黑箱里制造廉价误会。

## 九、第四章《你送我剑的时候，已经想过这一天》

**本章先让玩家知道，主角暂时不知道。**切到明确标注的鸦羽视角。她以王庭旧执刑人的暗号联系女王，在蔷薇行宫外停泊的王船上交涉：交出血契剑，换绯月自由离开；如王冠需要承担者，她愿意替代。

女王让她看自己已经晶化到肘部的手臂，平静说明契印十年前已定，不能随意换人。鸦羽的交易没有成立。

**女王：**你既然拿走她最舍不得的东西，就应该知道她一定会追来。

鸦羽试图摧毁剑柄，被近卫压住。女王夺回剑，随即因晶化发作必须返回王城，命负责王冠手术的“缀身夫人”在行宫检查契印、收押鸦羽，等妹妹追到后一起押送。这里女王成功抓人，但不是预知每一次追踪与战斗；她离开正是小队能反夺证物的机会。

剧情切回绯月。玩家知道鸦羽不是投敌，也知道女王想做什么，开始期待绯月何时有勇气承认眼前证据。她和雪璃的对话可以有不同温度，但不能把答案拖到第六章才说。

| 任务 | 地点与剧情驱动 | 玩家行动、完成判定与结果 |
|---|---|---|
| `R-4-01` 她走的是王庭的路 | 蔷薇荒园。循鸦羽留下的黑纱与药瓶到旧行宫，遇到巡逻外科甲偶 | 用伤药痕迹辨别她是在赶路还是被拖走，穿花架与排水沟进外墙；绯月选择继续追她，而非只找剑 |
| `R-4-02` 合身的新衣 | 刑偶工坊。为王室定制的礼服和战斗模拟偶留在工台上 | 对照订制日期、尺寸修改和契印模型；发现绯月的新加冕礼服已制作多年，不是临时救姐姐的工具。打开试衣架机关进入内宅，普通工匠可自愿逃离 |
| `R-4-03` 别人替你选好的房间 | 嫁衣长廊。姐姐替妹妹布置了十年前说想住的房间，物件是真的，期待却被冻结在童年 | 调查旧木马、身高刻线、未送出的信，允许停留读可选细节；在礼服箱底取王船交接单，确定鸦羽被押入地下，停止把她当作叛逃者 |
| `R-4-04` 我不是来替她问罪的 | 花眠庭院地下拘留间。鸦羽被束缚，旧伤正在恶化 | 雪璃稳住伤情，绯月解除与门锁相连的刑具，拿到拘留记录；不用打倒鸦羽才能听真话。她完整交代夺剑、交易和女王回答，向两人道歉 |
| `R-4-05` 现在把剑拆开 | 镜墓改为反光防潮的手术档案室，无梦境、记忆迷宫或假童年。缀身夫人把血契剑存入器械柜 | 三人按第二章底稿拆外饰、显露与剑柄同体的契印，以母晶测试片验证“刺心即继位”；全过程操作可复查，错误只暂停。查得母晶只在继位仪式开启，是可反制的实体弱点 |
| `R-4-06` 请殿下不要损坏自己 | 倒影剧场改作外科示范厅。缀身夫人视妹妹为要交付的继任身体，封门准备麻醉 | 击败夫人与手术偶，保住契印模型及解除步骤，从装卸水道逃出行宫；绯月亲手给暴露的剑柄套上防护匣，不再把剑当不可检查的圣物 |

**章节 Boss：缀身夫人·瑟芮。**十年前主持女王手术的宫廷外科师，知道继位将毁掉妹妹，仍以技术成功为荣。前半以针索、器械臂和麻醉雾逼迫分散；玩家关通风阀、切吊索，保持同伴能互相接应。后半她启动大型手术偶，自己躲进透明胸舱指挥；击断承重臂后打开胸舱。她始终称绯月“下一位陛下”，语气礼貌，行动冰冷。

**本章必须发生的情感场景：**确认契印不是普通修饰后，绯月看见十年前的制作日期。

**绯月：**她送我的时候，就知道？

鸦羽没有用推测冒充证据。雪璃把亲笔验收单放到她手边，让她自己看完。

**绯月：**我练不好，她就握着我的手教。她说，这把剑会保护我。

**雪璃：**它确实保护过你。

**绯月：**那我该恨哪一部分？

雪璃坐下，没有马上给答案。这段演出允许沉默，不用一句“向前看”结束。

**章末转折：**绯月决定不进王城。她要带两人回边境，拒绝继位，也拒绝替姐姐完成这场死亡。故事允许这个决定先成立；她后来重返王城必须有新的理由，不能由旁白劝她完成既定任务。

## 十、第五章《我们本来可以回家》

**情感起点：**这一章开头短暂放松。小队到月舟码头找回边境的船。绯月问雪璃想去哪，雪璃说先找一家不漏雨的旅馆；鸦羽为方才的独断付出信任代价，主动把合同、药和武器信息放到桌上。

**新事件：**王冠接近崩溃，血潮开始越过海堤。来不及撤离的普通人也向码头挤。女王近卫舰队封锁渡口，任务是将绯月完整押回，不允许小队带着继位器离境。女王没有取消妹妹的拒绝权，而是从一开始就不承认她有这个权利。

玩家先真正获得回家船票，再被新事件打断。这样“留下”是面对已看见的处境重新作出的选择，不是从未提供过的假自由。

| 任务 | 地点与剧情驱动 | 玩家行动、完成判定与结果 |
|---|---|---|
| `R-5-01` 三张回程票 | 雾汐堤岸与码头。船长愿载小队离开，但船损一根转舵杆 | 找木料、修转舵并试航一小段，完成真实可用的回程船；播放分食果酱、谈旅馆的日常。第一次让三人讨论共同的未来 |
| `R-5-02` 船上多了七个人 | 沉舟滩。海堤被突破，幸存者藏在一艘侧翻船里 | 按水位预警从高处开舱，先给伤员系绳，再带其他人走甲板；救出后调整船载重，允许先分批送最近安全岸，不做“七人选五人”的假难题 |
| `R-5-03` 她派船来接你了 | 潮盐工事。近卫封港，对绯月承诺只要她上船就放同行者离开 | 观察扣船与装卸安排，找到“同行者分开处置”的押运仓，决定不交人；夺闸控、把民船从锁链间放出。女王的温柔条件再次与实际准备对照 |
| `R-5-04` 如果什么都不做 | 沉钟遗迹改为旧海防遗址，地名保留，场景不安排钟作为剧情器物。众人寻找避潮高地 | 用本章潮痕和手术图测出母晶失控会持续扩大血潮；引居民到高处，守住短撤离战。绯月看见回去也无法置身事外；带领小队提出利用继位仪式毁掉契约 |
| `R-5-05` 这一次先把计划说完 | 逆潮水道。近卫舰挡住最后海口，小队拟定反登舰行动 | 勘查舰炮盲区、放出诱饵船、布置民船撤离标志；ADV 中由玩家按证据确认王冠—契印—母晶三目标，错误可讨论修正。鸦羽公开每一步并留备援路线 |
| `R-5-06` 让他们先走 | 归航灯塔下的军舰锚泊区。绯月不再等姐姐允许，主动攻击舰队控制船 | 小队登舰、破缆弩、击败舰队统领，保持民船通道开放；船长送难民去安全岸，按约回来接三人前往王城。她们有撤回机会，仍共同选择进城 |

**章节 Boss：黑帆提督·莫罗。**掌握妹妹行踪的强硬近卫，前半章通过炮口、登船检验与押运条件出现。他站在倾斜甲板上用重锚和短炮封路；玩家先破缆弩，使被扣民船离开，再利用空出的舷边与掩体反击。第二阶段他砍断锚链试图驶离，小队锁舵、近战击败他。港口操作来自前面修舵与观察甲板的任务，不临时变成全新海战系统。

**章末演出：**船长问这次要把船停在哪里等。绯月本想说不用等，停了一下，指向大教堂下方的旧水门。她与两人约定一起回来。

**情节意义：**三人回王城的理由变为“结束仍在伤害所有人的契约，并夺回自己的选择”，而非继续替姐姐完成遗愿。她们已经找到方法，也愿意共同承担行动，不再各自拿命偷偷交易。

## 十一、第六章《姐姐，把剑放下》

**入城状态：**女王知道妹妹正在接近，宣布封城并开始加冕准备。晶化已侵蚀她胸腹，六翼却更锋利。她仍能召回近卫、控制大教堂，不能被描写成只剩求救能力的病人。

全章先让玩家利用早先证据进入王城，不再连续抓一批人、换一张通行证；最后半章集中在姐妹见面、立场碰撞与一场完整 Boss 战。

| 任务 | 地点与剧情驱动 | 玩家行动、完成判定与结果 |
|---|---|---|
| `R-6-01` 约好回来的地方 | 朝圣大道旁旧水门。以船长的退路作为最终营地入口 | 实际开水门、放下绳梯、清掉落石，确认担架也能通过；建立最终回程检查点。进入前可返回旧地区，不提前锁自由探索 |
| `R-6-02` 不走她铺好的红毯 | 圣血外廊。正门是押送陷阱，第二章医师提供旧维修入口 | 用已有手术图找通风井、避开验血机关，关隔断不必杀所有守卫；到侧廊后能从内打开回营门，玩家感到前章救人确实改变通路 |
| `R-6-03` 你可以不用一个人来 | 失乡庭院。女王遣退侍从，要求妹妹独自入殿，许诺让同伴安全离开 | ADV 选择“当面拒绝”或“表面答应、同伴走侧道”；两路均让同伴知情并参与，差别是前门短战或侧路潜入。已建立的合作不能被假选项撤销 |
| `R-6-04` 王座下面是什么 | 彩窗工区至大教堂下层。母晶装置只在仪式开启后暴露，需预先到达其外壳 | 依手术模型识别束缚扣、拆外壳护架、固定提灯支点与撤离绳；此时无法直接破母晶，现场给出明确封闭反馈。队伍具备终局执行位置 |
| `R-6-05` 你真的想让我杀你吗 | 王座大教堂门前。确认不可逆进入并备份，播放重逢完整场景 | 允许先回营。入场后绯月与女王对话，雪璃、鸦羽按已说明的路线就位；拒绝刺心，女王拔剑，开始同一场终局战 |
| `R-6-06` 不再有下一位女王 | 王座大教堂，三阶段连续战与源核破坏 | 破六翼防护、裂冠、阻止强制刺心、毁契印与母晶，三人协同奥义释放；女王失去控制，血潮散去。救援选择在胜负确定后处理，不复制最终奖励 |

### 重逢场景样稿

【背景】女王桌上有两只杯子。一只盛着她自己喝的苦药，另一只放了过多的糖。她还记得妹妹十年前的口味。

**女王：**你以前最讨厌苦的。

**绯月：**我现在也会喝。

女王看见剑柄上的拆卸痕迹。

**女王：**你把它拆开了。

**绯月：**你想先问我路上有没有受伤，还是先问我看见了多少？

她们都没有碰杯子。

**女王：**我确实想活下去。十年了，谁都可以告诉我再坚持一天。你也要这样说吗？

**绯月：**你写信的时候，想的是我，还是下一位能坐在这里的人？

**女王：**我把最安全的剑留给你，派人看着你。你长大的每一年，我都——

**绯月：**那你为什么从来不见我？

女王回答不了这个问题。后来她还是把手伸过去。

**女王：**只帮我这一次。

绯月没有把剑交给她。

**绯月：**我来，是因为你是我姐姐。我不照你说的做，也是。

女王看向侧廊亮起的青光，知道她并非独自赴约。六翼张开，挡住门口。

### 女王战：三阶段分别改变姐妹关系

**章节 Boss：血潮女王。**这是本章唯一强制大 Boss，前几项任务不再安排必须逐一击败的独立首领。

**阶段一，旧剑路。**绯月正面交锋，女王熟悉她曾教的招式。连续追击会被挡反，玩家用停顿、变向与闪避寻找窗口。保留 PV 女王环形预警、绯月向安全中心闪避、双剑相交。这里先表现两人确实有过共同生活，而非打完补一页身世。

**阶段二，不许她们靠近。**女王六翼分区攻击，试图将雪璃、鸦羽隔出战场。玩家破坏翼根护晶，三人按预布支点互相解围；青色保护域抵挡大范围冲击，紫色刀路切开束缚，赤刃完成破冠。女王发现妹妹的剑术已经不止自己教的那一部分。

**阶段三，把你的命还给你。**女王启动继位，王座外壳打开，企图控制绯月的剑刺入自己心脏。玩家提前获得过完整风险说明，目标明确是阻止刺心、转刃破母晶。雪璃压住晶潮，鸦羽断王座扣，绯月攻击母晶而非姐姐。三人奥义汇成玫瑰窗光纹，母晶与王冠破碎。最后主动折断已经暴露的继位契印及剑柄，封住再次继承的可能。

继位仪式是女王主动发动的机会，小队只是把早先查明的步骤用上。不会在最后突然宣布“友情可无视王冠规则”。环形、分区与合作窗口的判定必须和预警一致；失败从阶段检查点重试，不重复长对白。

女王没有突然变好、主动替妹妹死去完成赎罪。她输掉战斗，失去力量，仍须面对自己的所作所为。

## 十二、终章《这封信不用再寄了》

### 结局与选择

血潮已结束，母晶已毁，黎明不会因为玩家最后救不救女王而消失。失去支撑的王座侧台开始坍塌，女王受伤倒在上面。

给出清楚的两项行动：**“与同伴固定绳索，把她拉回来”**／**“带同伴撤出，让她留在王座”**。救援具备第六章主线已准备的绳索与通道，没有隐藏好感门槛；撤离会让女王死亡，选项说明与镜头清楚呈现。两项都结束血潮，不用“好／坏结局”替玩家评价感情。

**救援收束《未寄出的回信》。**绯月救下姐姐，说明这不是同意替她继位，也不是替受害者原谅。女王作为失去王权的重伤者被看守、接受调查。病房里她第一次问妹妹想去哪里，没有提出自己的安排。绯月说还没决定，暂时不留在王城。

**告别收束《把剑留下》。**三人按约撤离。绯月将折断的剑柄放在旧水门边，只带走姐姐最初的信。没有临终一句话将所有伤害化解，只有她日后仍要面对的选择。

两路共有 PV 画面：雪璃左、绯月中、鸦羽右，站在仍然破损的城垛上，风暴退去，晨光出现。随后交还操作，完成 `R-E01`“回到等我们的人那里”：走到旧水门、见船长、向同行者报平安。

返程的船上，雪璃问绯月那封信还留不留。绯月取出它，翻到空白背面，却没有立刻写。鸦羽把干燥的笔递过去。

**绯月：**先去找那家不漏雨的旅馆吧。

信不必在结尾替所有人总结道理。三人第一次能决定旅途之外的生活。

## 十三、可选任务：补关系与世界，不补主线漏洞

先设计六条，每章一条。主线所需的王冠规则、证据和入口全部在主线提供；不要求刷个人好感解锁“看懂故事”。

| 任务／开放时机 | 实际玩法 | 人物与后续变化 |
|---|---|---|
| **修好之后也别扔**／第一章村医庇护后 | 为雪璃修被箭擦裂的提灯护罩，找旧玻璃、与工匠确定透光角度，试照一段暗路 | 绯月第一次主动照料同行者的东西；护罩保留可见补丁。无 Boss，不需要三次跑腿随机刷材 |
| **不属于委托的报酬**／第二章医师获救后 | 查鸦羽伤药配方，在旧药房以药箱标签辨出替代品，试制稳定剂 | 医师正是她当年拒绝处决的人，解释他为何愿意提供入口；鸦羽将病情说出，不靠隐藏药瓶继续吊悬念。无 Boss |
| **山里有人等你回去**／第三章后 | 回矿坑侧路接回一队失散旅人，修升降架并封一段兽道 | 可选小 Boss **霜脊岩兽**：岩甲冲撞、落石反击；完成后高地营地出现旅人，可寄出后续消息 |
| **现在穿也不算晚**／第四章旧居调查后 | 从未送信件找出姐姐曾想寄出的小礼物，为其中一件做普通修补；玩家可带走或原样留存 | 证明姐妹间真实关爱与伤害同时存在。物品不增加原谅值，不成为救女王钥匙。无 Boss |
| **下一次别逞强**／第五章船修好后 | 小队做一次不带剧情危险的海上救援演练，玩家交换角色完成拉绳、照明、护送 | 解锁一段有笑声的营地日常，强化终局绳索救援的视觉语言；基础绳索主线仍提供。无 Boss |
| **被留下的房间**／第六章终局前 | 返回王庭拘留室，按第二章医师名册找仍被关押者，开锁护送到水门 | 可选小 Boss **牢狱看守·铁棺**：重盾封路、锁链拖拽；救出者后日谈作证，不以做没做改变主线事实 |

如果后续需要扩展支线，先围绕已有配角的生活与行动展开。不要为每张地图硬造一位有冤情的 Boss，也不要新增几十个专有名词解释一个简单冲突。

## 十四、ADV 结构与制作要求

### 关键伏笔与回收

| 首次出现 | 玩家当时的理解 | 后来如何回收 |
|---|---|---|
| 开场信使先认剑，才交信 | 姐姐用旧礼物确认妹妹身份 | 必须到场的是妹妹和继位器，不只是一个想重逢的人 |
| 追缉令“绯月不得损伤” | 她仍受姐姐保护 | 她被保护的是将被交付的身体，同行者从未受同等保护 |
| 鸦羽称任务“改过一次” | 佣兵隐瞒委托内容 | 她早知护送掺入抓捕，第一章后主动交完整合同；不拖到离队才全部解释 |
| 维恩真的解围、提供住处 | 童年熟人值得信任 | 他愿意照顾她，但更愿意替女王决定她的未来；早期善行不能替后来的出卖免责 |
| 工匠发现不能粗拆的剑柄 | 姐姐礼物藏着危险 | 第四章绯月自己下令拆开，人物成长落实在一次操作上 |
| 女王说“她看得清” | 相信长大的妹妹能读懂遗书 | 结尾妹妹看清之后拒绝她；女王不能再把妹妹的理解等同服从 |
| 旧房间和过甜的杯子 | 姐姐仍记得妹妹 | 关爱停留在十年前，不表示理解现在的妹妹；这些细节不都是伪造 |
| “一起出这扇门” | 开场临时合作条件 | 矿坑、夺剑后的道歉、最终水门返程反复用行动兑现，不反复喊同一句口号 |

### 选择怎样产生差别

- **调查选择改变准备。**第三章提前识破伏击会保留通路、改变雪璃所在位置；剧情读取事实，不能照常播放“毫无察觉被抓”的过场。
- **表达选择改变关系场景。**绯月可立即解释或稍后道歉，鸦羽可先接受质询或先救伤；保留具体对话变化，不将所有台词折算成一个隐形好感数。
- **路线选择改变操作。**邮检室潜入或清路、王庭前门拒绝或侧路潜入都具备独立目标与后果，同主线信息不重复刷。
- **最终选择改变人物命运。**救或不救女王明确、可理解，结局先由主线完成度保证，再读取这次行为。关键真相不藏到二周目才补全。

正文写作按“场景目的—人物想要什么—阻碍—动作／对白—局面变化—任务目标”逐场展开。每段强制演出必须至少改变一项信息、关系或处境；路上对白可短，关键争执需要完整来回与沉默，不用旁白一句“她意识到”代替表演。

### 任务、存档与执行边界

任务日志写眼前意图：“查信使经过的马厩”，不要提前泄露“查出姐姐要你继位”。角色未获知的信息只能写在玩家回顾的明确视角标签中，不能让绯月突然引用鸦羽单独场景。

调查证物为固定来源，证据结合有可见依据，可回查与纠错；护送失败从安全点续接，警戒暴露转普通遭遇，必需线索不占可售背包。设施、证据、分支和奖励独立保存，先探索后接任务有效。演出跳过后保留摘要、选择与目标，不重复奖励。

内容数量为序章 3 项、六章各 6 项、终章 1 项，共 **40 项主线**；另有 6 条可选任务。强制大 Boss 为 **6 位**，本稿明确新增的可选小 Boss 为 **2 位**。不是每个区域、每个任务都打 Boss。

现有六章地图可作为场景资源基础，但旧名字不约束新剧情：修院、广场、海防遗址中的“钟”字只属地图历史命名，既无鸣钟引导剧情，也无相应能源设定；制作前可统一改显示名，内部地图 ID 与存档地址保留。新任务编号与旧任务条件不能直接混用。

推荐首个制作切片为 ADV 开场至第一章结束：先写完整可演对白和证据交互，再制作追杀护送、驿站查证、礼拜堂血晶、审判官战与第二封信。通过连续试玩确认玩家能说出“我为什么去、我信谁、证据改变了什么”，再扩第二章。
