# 《赤月遗书》全游戏流程与剧情触发表

2026-10-15 · 制作方案 v1 · 配套 [故事大纲](STORY-REBOOT-ADV.md)／[CG 与动画制作表](STORY-CG-PRODUCTION.md)

本文覆盖新战役、序章、六章、两个结局、通关回访。剧情事实以《赤月遗书》为准，不混入前三版故事。40主线、6支线及分支通过新事件层接入，基础地图和渲染恢复使用原项目，只按剧情增补局部内容。正式影片仍为空路径，由叙事过渡衔接。具体实现与另外制作范围见[实现说明](SCARLET-IMPLEMENTATION.md)及[制作缺项](SCARLET-REMAINING.md)。

## 1. 从开始到结束的一条完整路径

标题页 → 新建故事战役 → 王座写信动画 → 客舍 ADV／信使遇袭动画 → 操作逃离客舍并救信使 → 营地自由整备 → 第一章追查信与追杀令 → 审判官战／第二封信 → 第二章查剑、救医师、结识维恩 → 法官战／维恩秘密传讯动画 → 第三章伏击、矿坑接应、维恩背叛 → 维恩战／鸦羽带剑离队 → 第四章鸦羽视角交涉失败 → 绯月追到行宫、救鸦羽、拆剑知真相 → 缀身夫人战／决定回家 → 第五章修好回程船 → 海潮救人／舰队封港 → 公开反攻计划 → 提督战／难民先走 → 三人主动驶向王城 → 第六章开水门、潜入、准备反制 → 姐妹重逢 → 女王三阶段战 → 三人奥义动画／毁掉契约 → 救女王或自行撤离 → 对应撤离动画 → 共同黎明动画 → 玩家走回水门 → 分支后日谈 → 船上回信场景／片尾 → 通关档回访。

**动画不是另一个故事。**调查所得必须在 ADV 与日志中成立，动画负责动作、空间和情绪高潮。未制作动画时用分镜占位也能连贯游玩；不能因视频缺失漏掉关键证据、选择或任务提交。

## 2. 演出和触发的统一规则

### 演出类型

- **ADV**：背景、立绘、对白、证据展开、选项、回顾。玩家控制翻页节奏。长争执、真相说明、重要选择放这里。
- **CG-xx**：专用插画；可做轻微呼吸、灯光、景深和平移，仍由 ADV 控制文字与退出。编号见制作表。
- **CIN-xx**：独立过场动画；视频期间停止玩家与敌人模拟，结束后落在确定的场景状态。建议时长为分镜预算，尚未计入配音实测。
- **EV**：游戏内短演出，如 NPC 开门、放绳、摆证物、转镜头。复用现有模型与动作，不要求另外做完整视频。
- **PLAY**：角色由玩家控制，探索、交互、战斗、护送和机关在这里发生。

所有过场默认可跳，跳过执行同一个结束事件并显示可回看的摘要。**选项不能被跳过自动替玩家选答案。**文字自动播放在选项处暂停；关键选择不设读秒。

### 触发与保存

每项任务分“入场触发／可操作目标／收束触发”。后续任务从前一项收束完成后开放，玩家可以继续探索，不要求立即奔向下一标记。剧情不能单凭碰地图边界反复播放。

`scene_seen` 保存已看场景；`facts` 保存已知证据；`choices` 保存明确选择；`world` 保存已开门、已救人和遭遇结果；`quest_steps` 保存任务过程。它们是拟新增职责，不声称当前已有这些字段。影片观看记录与世界事实分开，鉴赏回看不改任务、奖励或分支。

触发优先级为：当前战斗／救援 → 待播主线 → 玩家主动交互 → 支线／环境短句。除已设计的突袭外，强制演出只在安全区开始；不能把玩家定在火圈里播对白。同一时刻只执行一个演出。

过场前保存稳定检查点，标记待播场景；播放完成或跳过后一次提交结果。中途退出重进时恢复该场景，可跳到结束；不出现“电影已看、任务没推进”或发两次奖励。区域加载完成、角色站位与镜头就绪后才淡入，影片最后一帧不能直接把人丢进攻击判定。

### 地图与新编号

本稿保留现有区域作制作底图，按新剧情设置事件；不承诺原碰撞、入口和任务锚点无需调整。旧地名中的钟不再承载设定，以下直接使用“边境修院、旧广场、海防遗址”等显示名，内部地图 ID 可保留。

新主线采用 `R-P01…03`、`R-1-01…R-6-06`、`R-E01`，共 40 项。旧任务存档需迁移或新战役隔离，不能把新编号直接写进旧运行档。

## 3. 新建战役与序章

### 标题页／新建

玩家确认新战役后创建独立存档；已有战役默认继续当前事件。首次开始设置 `story_started`，加载客舍地图到隐藏状态，先播放 `CIN-00`。标题页不能把结局影片当作随机背景，避免提前泄露。

### R-P01 一封遗书

1. **新战役首次进入**：`CIN-00 王座上的信`，女王写信、手部晶纹、缺角蜡印。结束切客舍背景，进入绯月与雪璃修剑鞘的 ADV。此刻玩家仅知道女王在写给绯月的信。
2. **信使核对剑柄、绯月打开信**：显示 `CG-01 两封矛盾的命令` 的第一层，仅见遗书；“带剑进城，亲手杀死我”可展开阅读。点击读完继续对话。
3. **信使看见窗影、转身推开绯月**：播放 `CIN-01 窗外的第二组弩手`，射击、挡窗、鸦羽进门。影片表现信使受伤，不能表现他死亡。
4. **回到 ADV**：雪璃止血，鸦羽说明护送身份，信使指出剑；`CG-01` 切第二层，显示追缉令与同样缺角蜡印。两份证物入线索袋。
5. **出现开场选择**：“我背他，你开路”／“先告诉我，你知道多少”。第二项先补问答再安排救援；均留下信使存活事实。选择结束提交 P01，淡出到客舍后廊，开启 P02。

开场整体由动画与 ADV 交替构成，预计阅读 5—7 分钟是节奏目标，不是一支 7 分钟影片。玩家选完后才出现完整操作 HUD。

### R-P02 先过这扇门

- **入场**：镜头先显示医棚方向，再交控制。绯月负责掩护／搬动，雪璃维持伤者稳定，鸦羽开路；首次用移动、掩体和交互提示教操作。
- **玩法**：推柜开后廊、沿掩体避弩手，或解决一组普通追兵，再把担架送进医棚。伤者倒下重置最近安全段，信使不会因玩家停留购物而暗中死亡。
- **收束触发**：担架进入医棚接收区且附近威胁清除。EV 医护接手 → 简短 ADV：“人还活着，现在轮到解释。”提交 P02，保存，开启 P03。
- **返回**：安全营地自由操作，追兵不会在这时凭空复生；暂无大型动画。

### R-P03 同行的条件

- **入场**：玩家主动与医棚外的鸦羽交谈；不因一靠近就锁镜头。
- **ADV**：检查箭头与扣件，鸦羽公开当前护送条件，雪璃决定同行。约定与安全有关的委托变更必须告诉同伴，明确先去驿路查信使行踪。
- **玩法**：营地补给、仓库、训练均自愿；第一次南门交互显示地区路线图，无需把全部 NPC 对话一遍。
- **收束触发**：确认出发并穿过南门。提交 P03，播放 3 秒 EV 三人出门，切第一章。回营入口立即可用，第一章标题出现后交控制。

## 4. 第一章：姐姐不会寄第二封信

### R-1-01 不许回头的路

- **触发**：首次从营地走入风铃原野，镜头短移到王庭搜查队，ADV 3—5 句说明不能把追兵引回医棚。
- **PLAY**：调查脚印、选择废车制造误导，经过岔道与浅河；清掉一组拦路者后抹去回营标记。不是清空全图。
- **收束**：追踪路被误导、阻路敌人解除、全队到河对岸三个条件满足；EV 搜查队转向，日志改为“找信使换马的驿站”。提交后开放 1-02，无 CG。

### R-1-02 信使换过的马

- **触发**：主动问驿夫信使去向，驿夫否认，开放调查区。
- **PLAY**：固定取得鞍扣、带浅滩泥的马蹄印、被涂去的一行账；证物菜单组合两项即可有效质问，第三项补充信息。乱试有提示，可回查。
- **收束**：驿夫在完整对话中承认接待过信使，交出礼拜堂接头信息，并提到审判官正在搜村。提交，开放村庄路线；证物可复读，无单独影片。

### R-1-03 今晚谁都没见过我们

- **触发**：到村医家门前主动敲门，短 ADV 谈庇护条件；任务更新为取药。
- **PLAY**：伪装交易、绕后潜入、正面击溃护卫三种路线；取固定药箱并送回，不需随机掉落。暴露转战斗，药不被永久销毁。
- **剧情触发**：交药且村屋安全 → 日落／室内 ADV → `CG-02 一碗热汤`。三人分床铺、处理提灯裂痕，鸦羽第一次主动将变更过的护送合同交出来；她承认此前被要求“到了驿站不得停留”，不预先知道全部继位规则。
- **返回**：提交 1-03，保存到次日安全村屋；开放支线 S01、礼拜堂调查及回营。休息由玩家确认，不因站够时间自动跳夜。

### R-1-04 圣物箱里的伤口

- **触发**：走到雾桥前安全观察点，ADV 交代桥索与红雾。修好桥索后，主动“带队过桥”。
- **动画一**：播放 `CIN-02 雾桥上的三个人`，建立 PV 跑桥队形；结束站在完整桥南平台，无敌人贴脸。
- **PLAY**：进入礼拜堂，按机关线索开圣物箱；绯月取唯一一枚血晶，雪璃照明、鸦羽望风。这段取晶用 EV，不再额外插另一支电影。
- **动画二**：灯角度与晶体槽位正确后，播放 `CIN-03 医疗记录`，仅展示女王晶化手臂及她批准秘密处置的那次记录。
- **ADV 收束**：三人讨论能证实什么、还不能证实什么；记录与晶体入袋，提交 1-04。门外传来巡逻声，给玩家明确选项“先回营”／“查看村里的情况”，不当场强制战斗。

### R-1-05 留在这里会害死他们

- **触发**：前往村庄方向的岔路，见被押村医的囚车，安全位置播放短 ADV。若先回营，此事件等待玩家回来，村医不会后台被处死。
- **PLAY**：截停囚车、开笼、点撤离灯标，护被抓者到浅滩安全站；随后绕修院侧院取封锁路图。
- **动画触发**：居民已安全、进入修院前庭且两侧普通遭遇已解除 → `CIN-04 三人突破`，鸦羽拔刀、绯月突进、雪璃护盾，对应 PV。影片中的小怪是专用演出角色，不占尚未击杀的场景敌人奖励。
- **返回**：落脚修院前庭安全角，提交 1-05，标记 Boss 入口；可回营最后整备。

### R-1-06 缺角的蜡印

- **触发**：玩家主动推主厅门，关卡提示“章节首领，战败可重试”。EV 审判官入场，ADV 承认追缉令真实，不播放独立长视频。
- **PLAY**：审判官两阶段战；拆弩台、挡链、互相解束。入场前存检查点；战败重试 Boss，不重做囚车和路图。
- **收束一**：Boss 败且传令匣取得 → 战后 ADV，完整命令揭示其他人不在保护范围；先发一次性奖励，开放返村／返营。
- **收束二**：玩家返回村医安全站，医护转交第二封信 → `CG-03 第二封信`，女王叫出两位同行者的姓名，绯月与雪璃争执。此处是本章真正的结尾，不能杀完 Boss 自动远送下一章。
- **章节结束**：读完保存；驿站联系人提供白垩商车。与车交互“前往白垩城”才提交交通与切图，落脚独立营地。未做 S01 保留可回访；沿路被救者已在安全地点。

## 5. 第二章：替她说谎的人

### R-2-01 叫我旧名字的人

- **触发**：在白垩营地收到工匠铺地址，从南侧外街进入首次巡逻冲突；EV 维恩挡开一次射击，短 ADV 叫出绯月小名。
- **PLAY**：与维恩清开街口、安置受伤路人，跟到真实可用的庇护点。此时他提供确实帮助，不在每句话都做反派暗示。
- **收束**：路人安全、避难门打开，维恩给工匠引见。提交，开放工匠调查；营地可补给，无 CG。

### R-2-02 姐姐送我的东西

- **触发**：主动把剑给工匠外检，他要求取被扣底稿。
- **PLAY**：到旧广场查封铺，按封店条和柜钥找底稿、模具，带回核对。固定线索，不随机刷护卫掉钥匙。
- **ADV 收束**：工匠发现剑柄不能粗拆；绯月暂时拒绝，雪璃记下待验证结构。提交后开启医师线索，剑仍可用于战斗，无动画。

### R-2-03 还活着的证人

- **触发**：工匠指认旧审判庭囚医位置，外门安全点讨论营救。
- **PLAY**：读取值班表、偷钥匙或解除守卫、开牢、带医师离开。医师被攻击倒下回最近安全站续接。
- **剧情触发**：医师进入避难房 → `CG-04 医师与旧伤`。他认出鸦羽，证实她当年拒绝处决的就是自己，解释“杀佩冠者不等于断契”。S02 在此开放，不把这层基本关系锁支线。
- **收束**：医师画出书库原图位置，提交任务，前往 2-04。没有提前得出“绯月一定继位”的结论。

### R-2-04 剑上没有写给你的名字

- **触发**：进入灰页书库，取得原图正文后开放装订检查。
- **PLAY**：按页码、切口和装订位置找到解剖页并叠合，确认剑编号属于继位器；保留书库路线探索。
- **剧情触发**：组合证据成功 → `CG-05 不肯交出的剑`＋完整争执 ADV。雪璃提出暂存武器，绯月拒绝并说出伤人的话；不是仅增加“好感-1”弹窗。
- **收束**：人物暂未和好，仍承诺先送医师离开。提交，安全退出书库，开 2-05；玩家可回营听一段不同温度的交谈。

### R-2-05 谁都别替我决定

- **触发**：护医师到地下炉渠入口，发现出口被法官封闭，短对白分工。
- **PLAY**：分段关蒸汽、打开排水门、护维修者和医师到安全支路；普通战斗可清路。
- **剧情触发**：医师已安全、蒸汽关闭后才发生道歉 ADV，绯月把原图交雪璃保存。玩家可选直接道歉或先承认怕见不到姐姐，两项都落实道歉而非强迫和好。
- **收束**：一条通礼堂的反向维护路开放，提交；Boss 前可回营。

### R-2-06 判决之前

- **触发**：主动进焚书礼堂。EV 法官与宣判甲偶，ADV 说明毁证与处置学徒的目的。
- **PLAY**：法官两阶段战，解除隔断令同伴汇合；战败仅重试礼堂。战胜后开侧笼救学徒、取手术书。
- **剧情触发**：回避难房交书，医师用模型演示契约转移但保留尚未验证的血亲条件；维恩安排次日越山。
- **章节动画**：玩家确认在营地休息后，先看维恩替绯月系护手的 ADV，再播 `CIN-05 夜里的路线信`。此片是玩家专知，绯月日志不出现“维恩已叛变”。
- **章节结束**：保存次日营地。玩家主动与维恩出发，切月晶驿站。以后回访医师可核实信使已恢复的见闻，补充细节不阻断主线。

## 6. 第三章：替你挡刀的人，也会把你交出去

### R-3-01 一条太顺利的山路

- **触发**：在月晶驿站与维恩确认山路，进入坡地后短 ADV 指出新路标。
- **PLAY／分支**：可调查伏击高点、挪走捕猎索并布置侧梯，或直接继续跟随。选择继续前弹出“尚未勘查，仍继续吗”，不暗中按逛图时长算分。
- **收束**：主动推进到下段山门时锁定 `ambush_prepared=true/false`，提交。未勘查也能完成后续主线，不丢核心真相。

### R-3-02 为谁设下的陷阱

- **触发**：维恩离开队伍后玩家到山门地面标记，两种分支各播 `CIN-06A` 或 `CIN-06B`，不得两支连播。
- **未准备**：影片只显示山门落下与队伍分隔；交控制后切索救近处队员。战段结束触发 EV 雪璃被带入矿坑，目标改“营救雪璃”。不能在玩家已成功到达她身边时再强行抓走，分隔从开场地形就确定。
- **已准备**：影片显示侧梯仍开放；玩家先护伤者从备路离开，雪璃主动带伤者进矿坑避弩，目标改“到矿坑接应”。不播放俘虏画面。

**阶段二结束条件**：三组翼根解除、阶段量清空 → EV 裂冠 → `CIN-15 继位仪式`，王座外壳打开、女王抓住绯月持剑手，母晶露出。影片在剑尚未刺心时结束，明确新目标“挣脱控制，转刃破晶”。母晶开启原因来自女王主动继位。

**阶段三：把你的命还给你。**依次完成雪璃稳场、鸦羽断扣、绯月转刃／攻击母晶的可操作协同节点。用清楚的目标提示与正常动作完成，不在长电影中插毫无预告的单帧 QTE。单人也可通过明确角色切换和指定互动完成，不要求三名真人同时在线。

**最终动画门槛**：稳定窗完成、王座扣解除、母晶破防并被打至终结阈值，显示一次“共同终结”交互。玩家确认后保存 `finale_finisher_ready`，播放 `CIN-16 三人奥义与断剑`。影片表现三人招式汇成玫瑰窗、母晶和王冠碎裂、最后折断剑柄契印；不再回到普通 Boss 血条。

**胜利提交**：影片完成或跳过后，统一设置母晶毁、王冠毁、契印毁、血潮结束、Boss 已败；发一次奖励。血契剑保留为破损剧情物，战后不继续装作完整剑战斗。通关自由战斗提供普通替代武器，不偷偷复原契印。

**战败／退出**：阶段一、二、三各有稳定阶段检查点，不让玩家反复看整段重逢；已有过场可跳。若刚达到终结门槛就退出，继续时恢复终结待播状态，不重发奖励。恢复战前备份则回到门外、恢复当时完整武器与准备，不保留本轮战胜状态混用。

## 10. 最后选择、共同黎明与两条后日谈

### 终局选择 F-CHOICE

`CIN-16` 结束、胜利结果落盘后，画面回到安全 ADV：王座侧台开裂，女王重伤倒在边缘。玩家和同伴没有战斗伤害，坍塌是叙事状态，不在选项期间实时杀人。

两项明确选择：

1. **固定绳索，把她拉回来。**说明“使用已准备退路救下女王；她会被看守并接受调查。”记录 `queen_resolution=rescue`。
2. **带同伴撤出，让她留在王座。**说明“她将无法逃出坍塌区；三人按约撤离。”记录 `queen_resolution=leave`。

确认前可读证据和回顾，决定后保存分支；没有隐藏好感门槛、超时默认选项或要求二周目才显示的救援键。选项与剧情分支本身不能被“跳过全部剧情”越过。

### 救援线／CIN-17A

播放三人固定绳索、拉出女王、沿已打开通道撤离；影片里不能让她自己突然站起跑走。结束在王城外墙医护接收点，EV 医护接手、女王受看守。记录存活，暂不播放宽恕或恢复王权的仪式。

### 告别线／CIN-17B

播放三人转身沿原路线离开、王座侧台塌落。女王镜头克制，不靠新遗言替所有伤害辩护。结束在同一外墙安全点，记录死亡；不出现救援线的担架、病房或女王存活对白。

### 共同黎明／CIN-18

两线完成撤离接收后，短 ADV “去外墙看看”。玩家沿安全墙道到观景交互点，确认后播放 `CIN-18 废墟黎明`。片中只有雪璃左、绯月中、鸦羽右三人，女王不站第四位。建筑保持废墟，风暴退去有晨光；这时才兑现 PV 结尾。

末尾淡回同一外墙的游戏镜头，开启 `R-E01`。不立即黑屏片尾，不替玩家完成回到船长身边的最后一段路。

### R-E01 回到等我们的人那里

- **触发**：共同黎明完成，日志显示回旧水门向船长报平安。
- **PLAY**：沿已开的退路返回，环境已无终局攻击，三人有极短松弛对白。不能因为通关就把死亡 Boss 重置在路中央。
- **告别线专属**：主动在水门边放下折断剑柄，`CG-16B 留在水门的剑`，只带走信。剑柄交互用剧情副本表现，不允许取回后再次继位。
- **共同收束**：见船长，医护／伤者各一句回应，主线完成并保存通关状态。玩家选择“启航，观看后日谈”或“先在营地停留”；后者可整备回访，影片不会自动无限等待触发。
- **救援线后日谈**：字幕“数日后”，`CG-16A 病房里的提问`，女王在看守下第一次问妹妹想去哪里；绯月暂不留王城。没有将受害者的原谅代为写进台词。
- **告别线后日谈**：相同时间推进，在营地用短 ADV 与两人确认归程，不出现病房。无需强行让两条路线每一幕长度相同。
- **最后共同 CG**：`CG-17 信的背面`，返程船上雪璃问信还留不留、鸦羽递笔，绯月说先找不漏雨的旅馆。淡出 → 制作人员名单 → 解锁所见结局鉴赏。

### 通关后

继续本战役进入真实战后营地，不默认把人退回“女王未败”的时间线。公共 NPC 与可回访地区保留已救、已开路的状态；危机期间才能看到的完整演出可以从鉴赏回看，缺失可选任务需用符合战后的目标版本或标记“战前章节回看”，不能让死者在自由地图上再发原委托。

提供独立“恢复决战前记录”入口以改最终选择，先说明将回到备份状态并保存当前通关分支；鉴赏收藏保留，两个世界状态不同时叠加。普通 Boss 重战采用无剧情的残响挑战，不重演押送、处刑和背叛，也不重复固定奖励。

## 13. 制作与验收顺序

1. **完整占位流程先连通。**40 主线、六支线的开始、目标、收束、旅行、选择与结局全部能走；未制作 CG 用同 ID 分镜与字幕占位。
2. **先做开场到第一章的完整切片。**用它确认 ADV 操作节奏、玩家可读线索、护送、Boss 前后以及 CG 与游戏画面的衔接。
3. **再做分支与终局灰盒。**第三章 A/B、第四章临时离队、王座双入口、六翼阶段与最后救援先验证，避免 CG 做完才发现站位或规则矛盾。
4. **按制作表交付电影和 CG。**同 ID 分镜、成片、字幕、音效对应；替换影片不改变任务事件。
5. **连贯试玩验收。**每章末能清楚回答“刚证实了什么、关系发生什么变化、为什么去下一站”。检查跳过、看一半退出、死亡、提前探索、满背包、回旧图、鉴赏回放都不丢线索或重复领赏。

本文件已经明确剧情播放时点与整条可玩路径；逐句对白仍以大纲已写场景为基础另行扩成场景脚本，不能把此流程表当成已经完成全部配音台本。
