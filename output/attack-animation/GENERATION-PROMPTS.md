# 攻击逐帧生图提示词索引

本次完成的 **10 个 Boss 攻击动作**的全部逐帧英文提示词见 [BOSS-PROMPTS.md](BOSS-PROMPTS.md)。该文件按 Boss 和第 2–8 帧整理；每一张使用的原始文本也保存在 `prompts/bosses/{boss}/attack/02.txt` 至 `08.txt`。

使用 Rolldek 的 `gpt-image-2.5-sunburst` 图片编辑 API，一次只生成一张动作帧。通常输入 1 为已确认的攻击首帧（抠除绿幕后为透明 PNG），输入 2 为紧前一帧；提示词要求保持身份、装备、朝向与画布边距，并使第 8 帧接近首帧。裂地者绘制时使用镜像参考，交付时镜像回原朝向。月海兽第 2 帧额外以第 3 帧作为中间姿势参照；一次返回的假棋盘格背景经过背景清理后才用于交付。

角色攻击动作的已有提示词和原件保留在 `prompts/heroes/` 与 `working/heroes/`。墓煜的后续生成已按要求暂停。
