# 晶刃战技：参考图派生素材

用户明确选择将「生成参考图里的特效部分」与自行制作的动态特效结合。

这两份素材由内置 imagegen 依据用户参考图重新制作，保留其粉色玻璃风格，并非从截图逐像素抠图，也未直接使用整招成品截图。

- `ribbon.png`：透明横向刀光，在动态曲面上按轨迹显示。
- `shard.png`：透明单枚晶片，独立设置方向、大小、抛散与淡出。
- `generation.json`：两次完整提示词、内置生成器原文件路径与用途。

PNG 原始 RGBA 未经裁切、抠色或二次绘制。导入开启 mipmaps 和 alpha 边缘修复，避免缩到实机尺寸时闪烁。运行路径仅为武器身份 600 的战技及同身份剧情入口。轨迹、命中点、闪光、停顿、地面反光均由引擎代码控制。
