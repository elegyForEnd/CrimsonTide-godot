# 游戏用攻击帧

9 组角色攻击（绯月、雪璃、鸦羽各剑、重剑、法杖）与 10 组 Boss 攻击，每组 `000.png` 至 `007.png`。由 `tools/install_attack_frames.py` 从 `output/attack-animation/` 安装。

脚部位置由 `tools/attack-foot-landmarks.json` 逐帧标注：同一只支撑脚鞋底对齐到固定位置，悬浮生物使用身体或盘绕部位锚点。每组使用同一画布和同一缩放比例，不按每帧的武器或姿势边界缩放。透明留白覆盖整组动作，保留完整武器。

游戏通过 `scripts/generated_attacks.gd` 和 `manifest.json` 加载。前四帧对应蓄力，后四帧对应出手和回收，`004.png` 对齐实际伤害时点；多段攻击按各段伤害时点重播。保留现有战斗速度，极快的武器可能在一个渲染帧内跨过相邻动画帧。新攻击图不叠加旧动画的角色倾斜、前冲、摆动或位移残影。

角色攻击在加载时按同一角色四张走路帧的平均头顶至落脚点高度缩放，剑、重剑、法杖均与走路保持相同的站立大小，整个动作保持该比例。缩放围绕脚部锚点进行，不因举高武器而改变角色大小；Boss 沿用各自的显示高度。原始生图中的腿形和步幅仍有变化，校准固定支撑脚，不能让两只脚的不同姿势同时完全重合。

墓煜沿用旧资源。待机、移动、受击、死亡保留现有动作。
