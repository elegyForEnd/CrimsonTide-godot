# 星霜佩剑：完整动作分镜制作版

本组仅供武器 606。依据 `output/weapon-606-action-reference/full-action-v1.png` 的六阶段动作分镜，使用内置 ImageGen 逐张制作七个独立透明原图；此前被否决的两套素材不参与本组。

`surface` 晶面、`charge` 聚冰、`impact` 接触碎裂、`ground` 地面霜裂、`shard` 独立碎晶、`mist` 冷雾、`trail` 轨迹残光。`manifest.json` 保存来源、原图 SHA-256、有效 UV 与宽高比；运行时不采样角色、树桩或完整分镜。

`weapon_606_reference_vfx.gd` 根据释放事件展开晶面；拖尾记录真实出刀头部的历史位置，最多 32 点、存续 0.23 秒。挥击产生 4 团薄雾，命中产生 7 团低冷雾，各有出生时间、速度、上浮、扩散、旋转与透明衰减。地面霜裂随出刀从人物前方向攻击末端铺开，目标处的密集碎晶与接触霜裂另外由真实命中生成。蓄力取消立即清理，所有装饰不改变伤害或命中。

查看 `output/weapon-606-reference/index.html` 中的原速、半速实机录像、动作分镜与素材。当前为待用户验收的第一把完成版本，不自动继续其他武器。
